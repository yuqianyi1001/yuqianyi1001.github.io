# 写在前面

这里是把《心经》逐句的白话和解释，整理成单独的一篇文章，方便读者查阅。《心经》暂时还没有制作对应的讲解视频，但不妨碍先把这篇文章整理出来；格式与《八识规矩颂》逐句解释一文保持一致。

本篇是**般若版**——解读全依「缘起性空」的般若中观立场。同一部《心经》，站在不同宗派立场会读出不同深意，后续还会另写**唯识版**与**如来藏版**，以资对照。

# 《心经》白话和解释（般若版）

* 经名：《般若波罗蜜多心经》，通行本为唐·玄奘大师译
* 内容：一卷 260 字，浓缩六百卷《大般若经》的心要——「心」即心髓、精要之意
* 校准基准：《大般若经》（玄奘译）、《大智度论》（龙树造·鸠摩罗什译）、《中论》（龙树造·鸠摩罗什译）
* 立场：般若中观 / 缘起性空
* 说明：每句给出经文原文 + 白话直译 + 义理解释 + 术语解释，引及的经论原文另列「参考」；全经解读以「缘起故性空、性空故缘起」的纯正般若思想为准

## 第一分 · 总纲：照见皆空，度一切苦

### 能观之人与所修之行

#### 观自在菩萨

*白话*：观自在菩萨（即观世音菩萨）。

*解释*：「观自在」既是这一位菩萨的名号，也是表法：先有般若之「观」，才有于诸法、于生死之「自在」。经首标出能观之人，表示下文的境界不是理论推演，而是观照实修的所见——凡能以般若观照而得自在的修行人，都是「观自在」。

*术语*：
- **观自在** = 梵文 Avalokiteśvara，玄奘译「观自在」，鸠摩罗什译「观世音」——同一位菩萨的两种译名
- **菩萨** = 菩提萨埵（bodhisattva）的简称 = **觉有情**——上求佛道、下化众生者

#### 行深般若波罗蜜多时

*白话*：修行甚深的般若波罗蜜多（智慧到彼岸）之时。

*解释*：标出所修之行与所在之时——甚深观照正现前之时。「深」是拣别于「浅」：但见人无我为浅，遍观一切法自性皆空（人空 + 法空）为深；这不是闻思层面的知解，而是与空性直接相应的观照。下句「照见五蕴皆空」正是此时的所见。

*术语*：
- **般若** = prajñā = 智慧——特指**照见缘起性空的智慧**，不是世俗的聪明才辩
- **波罗蜜多** = pāramitā = **到彼岸** / 度——从生死此岸度到涅槃彼岸

#### 照见五蕴皆空

*白话*：观照而亲见：构成身心的五蕴，全都是空。

*解释*：「照见」是现观亲见，不是推理想象。「空」是自性空——五蕴没有独立、不变、自成的实体——不是说五蕴不存在。为什么五蕴皆空？因为五蕴都是因缘和合而起：凡待缘而生的，必无自性。

*术语*：
- **五蕴** = **色**（物质现象）/ **受**（感受）/ **想**（取相、概念）/ **行**（造作、意志等心理活动）/ **识**（了别）——佛对「身心一切现象」的五分归类
- **照见** = 般若观照的**现观**——亲见
- **空** = **自性空**（无自性）——**不是「没有」「不存在」**

*参考*：
- 《中论》：「因缘所生法，我说即是空。」

#### 度一切苦厄

*白话*：（因此）度脱了一切苦难灾厄。

*解释*：度苦不靠别的，正靠「照见皆空」：苦从执五蕴为实我实法而起；照空则执破，执破则贪嗔无从生起，苦厄自息。这一句是全经总纲——后文一切「无」字都在展开「五蕴皆空」，末尾「能除一切苦」与此首尾呼应。

*术语*：
- **苦厄** = 苦难（内的烦恼逼迫）+ 灾厄（外的灾患障难）
- **苦的机制**：不了缘起性空（**无明**）→ 执五蕴为实我实法 → 起贪嗔取舍 → 造业 → 受苦
- **度苦的机制**：照空 → 破无明我执 → 贪嗔无从生起 → 苦厄自息

## 第二分 · 色空不二：即缘起而性空

### 破「色」与「空」为二的误解

#### 舍利子

*白话*：舍利弗啊！

*解释*：呼唤当机听法之人。舍利弗是佛十大弟子中「智慧第一」——般若之义甚深，故对智慧第一的弟子宣说。

*术语*：
- **舍利子** = 舍利弗（Śāriputra）——母亲名「舍利」（鹙鹭鸟），故称「舍利之子」

#### 色不异空，空不异色

*白话*：色不离空，空也不离色。

*解释*：色与空不是两个东西：色之外没有另一个空，空之外没有另一个色。前半句破**执实有**——以为色是实在的、离空另有其体；后半句破**执断灭**——以为要离开色、消灭色，才能另外找到一个「空」。空不是把色消灭以后剩下的东西，而就是色的本性——这是般若与「虚无主义」的根本区别。

*术语*：
- 「不异」= **不离**——两者不相离、不相外
- **色**：定义见「照见五蕴皆空」句

#### 色即是空，空即是色

*白话*：色就是空，空就是色。

*解释*：从「不异」到「即是」是递进：「不异」还容许是两个东西互不相离，「即是」直指不二。「色即是空」是**当体即空**——色就其当下本身即是空，不必等色坏灭之后才见空；空就在色正现起处。「空即是色」则须简别：**不是**说有一个叫「空」的本体变现出色（空不是「体」，不是能生色的母体）——而是说空不在色外、离色无空可得：缘起与性空本是一件事的两面，因为待缘而成，所以无自性；正因为无自性，才能随缘现起为色。空不但不否定现象，反而是现象得以成立的原理。

*术语*：
- 「即是」vs「不异」：**不异**（不相离）→ **即是**（当体不二）——遮诠渐深

*参考*：
- 《杂阿含》232 经：「眼空，常、恒、不变易法空，我所空。所以者何？此性自尔。」——「当下即空」的《阿含》经证
- 《中论》：「以有空义故，一切法得成；若无空义者，一切则不成。」

#### 受想行识，亦复如是

*白话*：受、想、行、识，也都是这样。

*解释*：四蕴各配「不异空、空不异、即是空、空即是」四句，展开即十六句。色是物质，受想行识是精神——合起来表示身与心、物质与精神无一法有自性，不是只有物质空而心识实有。

*术语*：
- **受 / 想 / 行 / 识**：定义见「照见五蕴皆空」句
- 「亦复如是」= 同样如此——省略展开的十六句

## 第三分 · 诸法空相:「八不」的浓缩

### 空性离一切相对之相

#### 舍利子，是诸法空相

*白话*：舍利弗啊！这一切法的空性之相……

*解释*：再唤舍利弗，引出更深一层：空性即是诸法的真实相状。实相以「无相」为相——空性不是一个可以被抓取的「东西」，凡可取着之相皆是因缘假相。下面三句，是《中论》「八不」的浓缩表达。

*术语*：
- **空相** = 空性（śūnyatā）——诸法**无自性**这一实相；「相」在这里指**真实体相**，不是形相
- **八不** =《中论》归敬偈：不生不灭、不常不断、不一不异、不来不去

#### 不生不灭

*白话*：不曾（真实地）生起，也不曾（真实地）灭去。

*解释*：若「生」有自性，应不待因缘而自起——但一切法皆待缘而起，故无实生；本无实生，何来实灭——灭只是缘散，不是一个实体被消灭。说「生灭」是世俗谛的假名安立，说「不生不灭」是胜义谛的实相：既不执实有生灭（常见），也不堕断灭空无（断见）。

*术语*：
- **二谛**：**世俗谛**（因缘假名中安立的道理）/ **胜义谛**（诸法实相的道理）——般若说法的基本框架
- **常见** = 执诸法实有恒常；**断见** = 执诸法断灭空无——般若双离两边

#### 不垢不净

*白话*：没有（真实的）染污，也没有（真实的）清净。

*解释*：垢与净相待而立：法性上没有一个实在的「垢」可除，也没有一个实在的「净」可得。这不是说凡圣不分、不用修行——恰恰相反：正因为烦恼无自性（不垢），烦恼才可以断；正因为清净不可得（不净），才不会执净而成为新的系缚。

*术语*：
- **垢** = 烦恼杂染；**净** = 离染清净——两者**相待而立**（无垢则无所谓净）

#### 不增不减

*白话*：不曾增加，也不曾减少。

*解释*：约凡圣位说：凡夫烦恼似「垢多」，成圣功德似「新增」；但就空性说，在圣不增、在凡不减——悟了不多一分，迷时不少一分；众生成佛，不是造出一个新东西，轮回受苦，也不曾亏损法性一丝一毫。三句合观：不生不灭约**体**、不垢不净约**染净**、不增不减约**凡圣**——三对六字，遍遣一切相对之相；既然空性离一切相，「空中」自然「无」一切法，由此引出下一分。

*术语*：
- **三对六字**：生灭（约体）/ 垢净（约染净）/ 增减（约凡圣）
- 下一分「空中无 X」的**无** = 无自性、不可得

## 第四分 · 空中无法：一切法不可得

「空中无 X」的「无」，都是「**于胜义空性中不可得、无自性**」，不是否认现象在世俗谛中的假有。这里也没有「破」掉什么——法本自空，无一法被消灭，般若只是如实照见。这一分依次列举蕴处界三科、十二因缘、四谛、智与得，说其皆不可得。

### 蕴 · 处 · 界不可得

#### 是故空中无色，无受想行识

*白话*：所以空性之中没有色，也没有受、想、行、识。

*解释*：承上：诸法空相既离一切相，故空中无一法可立。世俗谛中，五蕴因缘假有、宛然显现；胜义谛中，五蕴无自性、了不可得——「无」是无自性、不可得，不是否认现象。这句总明五蕴不可得，即三科的第一科。

*术语*：
- **二谛**：定义见「不生不灭」句
- **三科** = 蕴 / 处 / 界——佛对「一切法」的三种开合归类

#### 无眼耳鼻舌身意，无色声香味触法

*白话*：没有眼、耳、鼻、舌、身、意，也没有色、声、香、味、触、法。

*解释*：十二处（三科的第二科）亦不可得：能取的六根、所取的六尘，皆是相待而立的缘起假名——根离尘不成其为根，尘离根不成其为尘，无一有自性。

*术语*：
- **六根** = 眼 / 耳 / 鼻 / 舌 / 身 / 意——能取的六种感官功能
- **六尘** = 色 / 声 / 香 / 味 / 触 / 法——所取的六种境界（「法尘」= 意根所对的观念、影像）
- 六根 + 六尘 = **十二处**——「处」= 生长门，识由此生

#### 无眼界，乃至无意识界

*白话*：没有眼界，乃至没有意识界。

*解释*：十八界（三科的第三科）亦不可得。至此蕴、处、界三科说尽——三科既是佛对一切法的归类，三科皆空即一切法无不空。为什么立了三科，又说三科皆不可得？立，是世俗谛中对治「执我」（分析身心为蕴处界，见其中无我）；说「无」，是胜义谛中对治「执法」（不复执蕴处界为实法）。

*术语*：
- **十八界** = 六根界 + 六尘界 + 六识界（眼识乃至意识）
- 「乃至」= **超略之词**——只举第一（眼界）与最后（意识界），中间十六界省略

### 十二因缘不可得

#### 无无明，亦无无明尽；乃至无老死，亦无老死尽

*白话*：没有无明，也没有无明的灭尽；乃至没有老死，也没有老死的灭尽。

*解释*：十二因缘于空性中亦不可得：流转门（无明乃至老死）无自性，还灭门（无明尽乃至老死尽）也无自性——既不执生死流转为实有，也不执还灭解脱为实有。这不妨碍修还灭之行，反而成立它：正因为无明无自性，无明才能尽；若无明实有，则永不可断。

*术语*：
- **十二因缘** = 无明 → 行 → 识 → 名色 → 六入 → 触 → 受 → 爱 → 取 → 有 → 生 → 老死——「乃至」再次超略中间十支
- **流转门**（顺观）：无明缘行……乃至生缘老死——生死轮回的缘起链条
- **还灭门**（逆观）：无明**尽**（灭）则行尽……乃至老死尽——解脱的次第；「尽」= 灭尽

### 四谛不可得

#### 无苦集灭道

*白话*：没有苦、集、灭、道。

*解释*：四谛于空性中亦不可得：不是否定四谛在世俗谛中的修行价值，而是不执「实有苦可厌、实有集可断、实有灭可证、实有道可修」。《中论》正面回答过这个问难：正因为一切法空、皆是缘起，四谛才能成立——若诸法实有不空，则苦不可灭、道不可修。

*术语*：
- **四谛** = **苦**（果：生死是苦）/ **集**（因：苦由烦恼与业集起）/ **灭**（果：苦可灭，即涅槃）/ **道**（因：灭苦之道，即八正道）——世间因果一对 + 出世间因果一对

### 智与得亦不可得

#### 无智亦无得

*白话*：没有智，也没有得。

*解释*：最深的一层：连能观的般若智、所证的菩提涅槃也不可得。若执「我有智慧可用、有果位可得」，这本身还是执著，仍是系缚——空是破执的药，执药还成病，所以「空亦复空」。至此蕴处界、十二因缘、四谛、智与得，无一法可执，直接引出下文「以无所得故」。

*术语*：
- **智** = 能观的**般若智**；**得** = 所证的**菩提、涅槃果**
- **空亦复空** = 连「空」本身也不立为实法——般若的彻底处

## 第五分 · 菩萨果德：无所得故，究竟涅槃

### 依般若而心无罣碍

#### 以无所得故，菩提萨埵，依般若波罗蜜多故，心无罣碍

*白话*：因为无所得，菩萨依止般若波罗蜜多，心中没有牵挂障碍。

*解释*：这是全经的枢纽句：上承「无智亦无得」（不可得之极），下启菩萨、诸佛的果德（正因无所得，果德方成）。心取着一法，即被一法所罣所碍；无所得，则无一法可罣心。

*术语*：
- **菩提萨埵** = 菩萨的全称
- **罣碍**：「罣」= 牵挂（如网罣物）；「碍」= 障碍

#### 无罣碍故，无有恐怖

*白话*：因为心无罣碍，所以没有恐怖。

*解释*：一切怖畏都从执「有我可失、有法可失」而来：执实有「我」，则怖「我」受损（死畏、恶道畏）；执实有「所有」，则怖失去（不活畏）。无所得者无可失，故无所怖。

*术语*：
- **五怖畏**（菩萨地前所有）：不活畏 / 恶名畏 / 死畏 / 恶道畏 / 大众威德畏——般若现前，五畏皆离
- **果德次第**：无所得 → 无罣碍 → 无恐怖 → 离颠倒 → 究竟涅槃——层层递进

#### 远离颠倒梦想，究竟涅槃

*白话*：远离颠倒和梦想，达到究竟的涅槃。

*解释*：颠倒是四种根本倒见，梦想是把缘起假相当作实有的虚妄分别——正如梦中执梦境为真。般若的涅槃不是逃离世间、别求一个实有的寂灭之所：涅槃即诸法空性，本自不生不灭。以无所得故，不住生死（悲故不舍众生）、不住涅槃（智故不执寂灭）。

*术语*：
- **四颠倒** = 于**无常**执常 / 于**苦**执乐 / 于**无我**执我 / 于**不净**执净
- **梦想** = 如梦的虚妄分别

*参考*：
- 《中论》：「涅槃与世间，无有少分别。」

### 诸佛同依般若成佛

#### 三世诸佛，依般若波罗蜜多故，得阿耨多罗三藐三菩提

*白话*：过去、现在、未来的一切佛，都依般若波罗蜜多，证得无上正等正觉。

*解释*：举三世，表无一佛例外——成佛必由般若，故称般若为「三世诸佛之母」。这里说「得菩提」是世俗谛安立；胜义中菩提亦不可得——与上文「无智亦无得」呼应，两不相违：「得」而无所得。

*术语*：
- **三世** = 过去 / 现在 / 未来
- **阿耨多罗三藐三菩提** = anuttarā samyak-saṃbodhi = **无上正等正觉**——「无上」（更无有上）+「正等」（遍知平等）+「正觉」（真实觉悟）
- **般若为佛母**：五度如足，般若如目——布施、持戒等若无般若摄导，不成到彼岸的「波罗蜜」

## 第六分 · 总赞与咒：显密双说

### 四叹般若

#### 故知般若波罗蜜多，是大神咒，是大明咒，是无上咒，是无等等咒

*白话*：所以应当知道：般若波罗蜜多是大神咒，是大明咒，是无上咒，是无等等咒。

*解释*：以「咒」赞叹般若：咒即总持，以少字总摄无量义——正如本经以 260 字总持六百卷之要。般若的「神力」不从外来：照空即是破魔，见实相即是光明。

*术语*：
- **咒** = 总持（陀罗尼，dhāraṇī）——以少字**总摄无量义**而不失
- **四叹**：**大神咒**（神力大——能破烦恼魔障）/ **大明咒**（光明大——能破无明黑暗）/ **无上咒**（更无一法在其上）/ **无等等咒**（无有能与之等者；一说：与「无等」之佛果相等）

#### 能除一切苦，真实不虚

*白话*：（般若）能除灭一切苦，真实而不虚妄。

*解释*：呼应总纲「度一切苦厄」——开头标宗，这里结成，全经首尾圆合。般若不是玄谈，度苦是可以验证的真实受用。

*术语*：
- **真实不虚** = 佛语诚谛——劝信之辞

### 说咒

#### 故说般若波罗蜜多咒，即说咒曰：揭谛揭谛，波罗揭谛，波罗僧揭谛，菩提萨婆诃

*白话*：所以宣说般若波罗蜜多咒，咒是这样说的：揭谛揭谛，波罗揭谛，波罗僧揭谛，菩提萨婆诃。

*解释*：前文以义理**显说**般若（照见五蕴皆空），末后以咒语**密说**般若——显说令人依解起行，密说令人离解直行；一显一密，同归「度到彼岸」。咒依例音译不翻，属玄奘「五种不翻」中的**秘密不翻**：重在音声总持、一心受持，不重字面训解。

*术语*：
- 梵音：**gate gate pāragate pārasaṃgate bodhi svāhā**
- 通行释义：**揭谛**（去 / 度）/ **波罗揭谛**（到彼岸去）/ **波罗僧揭谛**（大家一同到彼岸去）/ **菩提**（觉悟）/ **萨婆诃**（速疾成就、圆满吉祥）——大意是：去吧！去吧！到彼岸去吧！大家一同到彼岸去吧！觉悟，速疾成就！

## 附二：「空中无 X」次第对照

| 法类 | 经文 | 法相门类 | 对治的执著 |
| --- | --- | --- | --- |
| 五蕴 | 无色，无受想行识 | 三科之一 | 执身心实有 |
| 十二处 | 无眼耳鼻舌身意，无色声香味触法 | 三科之二 | 执能取之根、所取之尘实有 |
| 十八界 | 无眼界，乃至无意识界 | 三科之三 | 执根尘识十八界实有 |
| 十二因缘 | 无无明亦无无明尽，乃至无老死亦无老死尽 | 流转门 + 还灭门 | 执流转、还灭二门实有 |
| 四谛 | 无苦集灭道 | 世间 + 出世间二重因果 | 执苦可厌、集可断、灭可证、道可修为实法 |
| 智 / 得 | 无智亦无得 | 能观 + 所证 | 执般若智、菩提涅槃果实有（空亦复空） |

**次第的方向**：从所观境到能观智——层层深入，最后连「空」的能所也不立，正显「无所得」。

## 附三：「空」的正解与误解对照

| | 误解的「空」 | 般若的「空」 |
| --- | --- | --- |
| 定义 | 什么都没有、不存在 | **无自性**——没有独立、不变、自成的实体 |
| 与现象的关系 | 否定现象（断灭见） | **不坏现象**——空即缘起现象的本性，「色即是空」 |
| 与缘起的关系 | 空与缘起矛盾 | **空故能缘起**——「以有空义故，一切法得成」 |
| 与修行的关系 | 既然皆空，无善恶、不必修 | **空故可修**——烦恼无自性故可断，佛道无自性故可成 |
| 与苦乐的关系 | 空谈玄理，与离苦无关 | **照空即度苦**——执破则苦息，「能除一切苦，真实不虚」 |
| 空本身 | 执「空」为一个实有的东西 | **空亦复空**——「无智亦无得」，空是破执之用，不立为实法 |

**一句话总结**：《心经》的「空」，自始至终是「**缘起性空**」——因为一切法待缘而起，所以无自性；因为无自性，所以能随缘现起、能转染成净、能从此岸度到彼岸。

—— 整理：愚千一
