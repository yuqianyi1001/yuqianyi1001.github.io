# 菩萨

## 词条概要

| 项 | 内容 |
| --- | --- |
| **梵语** | bodhisattva(बोधिसत्त्व) |
| **巴利语** | bodhisatta |
| **音译** | 菩提萨埵(全称),简称"菩萨"。古译又作菩提索多、冒地萨怛缚、摩诃菩提质帝萨埵等 |
| **意译** | 觉有情、大觉有情、道众生、道心众生 |
| **词源** | bodhi(觉、智、道) + sattva(有情、众生;另一义为"勇猛")。合义即"觉悟的有情"或"勇猛求觉者" |

---

## 一、基本定义(入门理解)

**菩萨,是立志成佛、并在成佛路上同时帮助众生觉悟的修行者。**

这个词的核心可以拆成两个动作:

1. 1. **上求菩提**——向上,以智慧追求佛的觉悟。
2. 2. **下化众生**——向下,以慈悲帮助一切有情解脱。

这两件事不分先后、同时进行,这就是菩萨与其他修行者最根本的区别。声闻、缘觉(罗汉、辟支佛)只管自己解脱;菩萨则发愿:**我要成佛,而且要带着众生一起到那里。**

> **一句话**:菩萨 = 立志成佛 + 不舍众生 的修行者。

需要注意:佛教语境中"菩萨"不是民间所谓的"神明"。观世音、文殊、地藏等大菩萨被礼敬,不是因为他们能赐福,而是因为他们示现了"上求下化"的圆满典范。

## 二、进阶理解(中级)

### 1. "菩萨"的两层语义

`bodhisattva` 在词源上有两种解读路径,经论中都被采用:

* **觉的有情**(玄奘新译"觉有情"):菩萨是已经觉悟、或正趋向觉悟的有情众生。
* **勇猛求觉者**(`sattva` 另一义为勇猛):菩萨是以勇猛心追求大菩提的人。

合起来,即《佛地论》所说:**"缘菩提萨埵为境,故名菩萨;具足自利利他大愿,求大菩提利有情故。"**

### 2. 菩萨与其他果位的区别

| 身份 | 修行目标 | 是否以度他为主要目的 | 最终果位 |
| --- | --- | --- | --- |
| 凡夫 | 趋乐避苦 | ✗ | 流转六道 |
| 声闻 | 自我解脱(听佛说法而悟) | ✗ | 阿罗汉 |
| 缘觉 | 自我解脱(独自观缘起而悟) | ✗ | 辟支佛 |
| **菩萨** | **成佛 + 度众生** | **✓** | **佛** |

声闻、缘觉合称"二乘";菩萨乘称"大乘"或"一乘"。在严格意义上,菩萨乘特指"摩诃萨"(mahāsattva,大菩萨),即追求**无上**菩提的大乘行者。

### 3. 菩萨的别名

经论中称呼菩萨的方式极多,各从不同侧面突显其德:

* **强调心量**:大士、高士、大心众生、大道心众生
* **强调身份**:开士(开悟之士)、始士(初发心者)、佛子、最胜真子(降伏子)
* **强调能力**:勇健、普能降伏、最胜萌芽、商主(导师)
* **强调德性**:大悲、怜愍、大福、大称(大名称)、自在、法师

这些别名背后是同一种人格:**有大愿、有大智、有大悲、有大行**。

### 4. 菩萨道的修行框架

菩萨修行的核心是"六度"(六波罗蜜):

| 六度 | 梵语 | 对治 |
| --- | --- | --- |
| 布施 | dāna | 悭贪 |
| 持戒 | śīla | 恶业 |
| 忍辱 | kṣānti | 嗔恚 |
| 精进 | vīrya | 懈怠 |
| 禅定 | dhyāna | 散乱 |
| 般若 | prajñā | 愚痴 |

后期大乘又加方便、愿、力、智,合为"十度"。这套框架是菩萨"自利利他"得以成立的方法论:前五度是慈悲的展开,般若是智慧的核心,二者缺一不可。

### 5. 菩萨的阶位

从初发心到成佛,菩萨经历多个阶段。最常见的体系是"五十二位":

> 十信 → 十住 → 十行 → 十回向 → 十地 → 等觉 → 妙觉

其中**十地**是从初地"欢喜地"到十地"法云地"的修行阶梯,被视为菩萨成熟期的核心位次。详细内容见独立词条 → [菩萨阶位]。

## 三、深入理解(高级)

### 1. 菩萨的多重分类

经论中对菩萨的分类极多,反映了对修行进程的精细观察:

#### (a) 按修行成熟度(《菩萨地持经》十种)

种性 → 入 → 未净 → 净 → 未熟 → 熟 → 未定 → 定 → 一生 → 最后身

熟者中:"一生"是再经一生即得无上菩提;"最后身"是此生即得。

#### (b) 按是否退转

* **阿鞞跋致**(avaivartika,不退转菩萨):修行不会倒退
* **鞞跋致**(退转菩萨):仍有可能退失菩提心

#### (c) 按身份状态

* **生身菩萨**:未断烦恼者
* **法身菩萨**:已断烦恼、得六神通者
* **生死肉身**与**法性生身**

#### (d) 按悟入方式

* **顿悟菩萨**:直入大乘
* **渐悟菩萨**:从二乘回小向大

#### (e) 按智悲倾向(法相宗特说)

* **智增上菩萨**:智慧倾向较强,顿悟者多属此类
* **悲增上菩萨**(大悲菩萨):悲心倾向较强
* **智悲平等菩萨**:二者均衡

### 2. 各思想系统的菩萨观

#### (a) 部派佛教

菩萨是**罕有的、特殊的修行者**,主要指释尊的过去生、以及未来佛弥勒。一般佛弟子的目标是阿罗汉果,菩萨道并非普遍开放的修行路径。这与后来大乘的菩萨观差异极大。

#### (b) 般若 / 中观

菩萨道的精髓在**般若**。菩萨度众生,但要彻见**无众生可度、无菩提可得、无菩萨可成**——这就是《金刚经》"应无所住而生其心"的核心。

> 度尽一切众生,而实无一众生得度者。

不是不度,而是度而不执。三轮体空(施者、受者、所施物皆空),才是菩萨行的真精神。否则修六度只是"有漏的善行",不是波罗蜜(到彼岸)。

#### (c) 唯识 / 法相

唯识宗对菩萨修行做了最系统的阶位描述,即**五位**(资粮位、加行位、通达位、修习位、究竟位)。其中"智增 / 悲增"的细致区分(见上文)亦出此系。

唯识强调菩萨修行的实质是**转识成智**——通过六度万行,逐步转八识为四智,最终成就佛果。

#### (d) 如来藏系

既然一切众生本具如来藏,那么菩萨的"上求下化"在更深层次上是:**显发自他本具的佛性**。度众生不是把对方"变成"觉者,而是**唤醒**对方本来就有的觉性。

这一进路使菩萨道在情感上更亲切——众生不是要被改造的对象,而是迷中的同伴。

### 3. 菩萨愿——不只是发心,而是绑定的契约

菩萨道的标志性特征是"愿"。著名的有:

* **四弘誓愿**:众生无边誓愿度,烦恼无尽誓愿断,法门无量誓愿学,佛道无上誓愿成
* **地藏愿**:地狱不空誓不成佛,众生度尽方证菩提
* **普贤十大愿**:礼敬诸佛、称赞如来⋯⋯恒顺众生⋯⋯普皆回向
* **阿弥陀佛因地四十八愿**:成就极乐净土、接引十方众生

愿不是情绪化的表态,而是**贯穿无量劫的修行承诺**——这是菩萨与一般"行善之人"的根本差异。

### 4. 历史上被尊为菩萨的人

菩萨不只是经典中的人物。历史上,印度大乘大师如**龙树、世亲、无著**被尊为菩萨;在中国,**竺法护**被尊为"敦煌菩萨",**道安**被尊为"印手菩萨";日本亦有高僧由朝廷赐封菩萨号。

这一传统提醒我们:菩萨是一个**可以走向的身份**,不是只能仰望的偶像。

## 四、常见误解辨正

| 误解 | 正解 |
| --- | --- |
| 菩萨是神明,能赐福消灾 | 菩萨是修行者(无论已成就或在路上),不是赐福之神 |
| 菩萨都是男身或女身 | 菩萨可示现一切身相;观音的女相是中土传统的演变,印度原型为男相 |
| 拜菩萨能得保佑 | 礼敬菩萨的本意是与其愿行相应、激发自己的菩提心,非交易性祈福 |
| 菩萨即指几位大菩萨 | "菩萨"是修行身份的统称,任何发菩提心、行六度者皆可名菩萨(虽有严格意义上的资格) |
| 菩萨与佛差别不大 | 菩萨仍在因位,觉行未圆满;佛是果位,觉行圆满。十地菩萨与佛仍有差距 |
| 行善 = 菩萨 | 不发菩提心、不修六度、不愿成佛者,行善虽好,严格说不属菩萨道 |
| 菩萨道太难,与我无关 | 大乘明言"初发心即超二乘";发心当下即入菩萨数,只是修行尚浅 |
