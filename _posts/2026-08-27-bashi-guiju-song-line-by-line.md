# 《八识规矩颂》逐句解释

* 作者：玄奘大师（造）
* 内容：四章十二颂四十八句，把唯识八识的体性、所缘、心所相应、烦恼配伍、凡圣转依，浓缩在 48 句颂文里
* 校准基准：《成唯识论》（护法等造·玄奘译）、《瑜伽师地论》
* 立场：玄奘唯识 / 法相宗
* 说明：每句给出颂文原文 + 一句话白话 + 术语解释；详细展开请看《八识规矩颂》系列四讲视频

## 第一章 · 前五识颂

### 第一颂 · 凡夫位基本特征

**性境现量通三性**

*白话*：前五识所缘是真实色法本身（不是想象，也不是带概念的执取）；当下直接感知（不做推理）；自己不能决定善恶，可以善、可以恶、可以无记。

*术语*：
- **三境**：**性境**（真实存在的境，直接感知）/ **带质境**（有真实本质但带一层概念，如末那缘第八见分执为我）/ **独影境**（心识独自变现的影像，如梦、想象、龟毛兔角）
- **三量**：**现量**（当下直接感知，无名言分别）/ **比量**（通过推理得到的正确认识）/ **非量**（错误的认识）
- **三性**：善 / 恶 / 无记
- **为什么前五识是「性境」**：因为只缘真实色法本身，不带任何概念执取
- **为什么前五识是「现量」**：因为直接感知，不做推理判断
- **为什么「通三性」**：五识自体不分别善恶，具体善恶由**心所搭配 + 第六识引发**共同决定

**眼耳身三二地居**

*白话*：眼识、耳识、身识 在欲界 + 色界初禅两地起；鼻识、舌识只在欲界起；二禅以上前五识全部停。

*术语*：
- 「三」= 眼识 + 耳识 + 身识（不含鼻舌）
- 「二地」= 五趣杂居地（欲界）+ 离生喜乐地（色界初禅）
- **三界九地** = 欲界 1 地 + 色界 4 禅天 + 无色界 4 定
- **有寻有伺地**（欲界+初禅）= 五识可起；**无寻无伺地**（二禅以上）= 五识全停
- 鼻舌为什么只在欲界？—— 色界众生已离段食欲（不需物质食物 / 香味）

**遍行别境善十一**

*白话*：跟前五识可以相应的善 / 中性心所，共 21 个——遍行 5 个 + 别境 5 个 + 善 11 个。

*术语*：
- **遍行 5** = 触 / 作意 / 受 / 想 / 思（一切心识必伴）
- **别境 5** = 欲 / 胜解 / 念 / 定 / 慧
- **善 11** = 信 / 精进 / 惭 / 愧 / 无贪 / 无嗔 / 无痴 / 轻安 / 不放逸 / 行舍 / 不害
- 合计 **21 个** 善 / 中性心所

**中二大八贪嗔痴**

*白话*：跟前五识可以相应的染污心所，共 13 个——中随 2 个 + 大随 8 个 + 根本 3 个（贪嗔痴）。小随 10 个 和 慢 / 疑 / 不正见 不相应。

*术语*：
- **中随 2** = 无惭 / 无愧
- **大随 8** = 掉举 / 昏沉 / 不信 / 懈怠 / 放逸 / 失念 / 散乱 / 不正知
- **根本烦恼**里只跟前五识相应的 **3** = 贪 / 嗔 / 痴（合计 13 个染污心所）
- **不相应**的：
  - **小随 10**（忿 / 恨 / 覆 / 恼 / 嫉 / 悭 / 诳 / 谄 / 害 / 憍）——「行相猛利」，唯各别起，五识无
  - **慢 / 疑 / 不正见**——需要计度分别判断，五识只有自性分别

### 第二颂 · 凡夫位所依所缘

**五识同依净色根**

*白话*：前五识都依「净色根」起。净色根不是肉眼可见的肉团（眼球、耳朵），而是整个感官机制的精微部分。

*术语*：
- **净色根** = 五根的体性 = 极微细净色（不是肉团）
- **扶尘根** = 肉团根（眼球、耳廓等）—— 是净色根的载体
- **现代理解**：净色根 ≈ 整个感官机制。如「眼根」相当于 眼球+视网膜+视神经+视觉中枢

**九缘八七好相邻**

*白话*：前五识生起需要的「缘」——眼识 9 个、耳识 8 个、鼻舌身各 7 个；缺一不能起。

*术语*：
- **眼识 9 缘** = 空 / 明 / 根 / 境 / 作意 / 分别依 / 染净依 / 根本依 / 种子
- **耳识 8 缘** = 去「明」（黑暗中也能闻声）
- **鼻 / 舌 / 身识 7 缘** = 去「空 + 明」（合中取，不需距离和光明）
- **分别依 / 染净依 / 根本依** = 第六 / 七 / 八识（都是「俱有依」）—— 唯识特色，反映八识相互依止

**合三离二观尘世**

*白话*：前五识取境分两种——眼识、耳识要有距离（离中取）；鼻识、舌识、身识必须接触（合中知）。

*术语*：
- **合中知** = 鼻识 / 舌识 / 身识（所缘境必须与根接触才能知）
- **离中取** = 眼识 / 耳识（所缘境与根之间要有空间距离才能取）

**愚者难分识与根**

*白话*：凡夫「愚者」容易把「识」跟「根」混淆——以为「眼睛能看」，其实要多个缘合力才能见。

*术语*：
- 「愚者」= 凡夫（未见道者）
- 常见误认：「眼睛能看」——其实是「眼识 + 眼根 + 色境 + 作意 + 种子 + …」等多缘合力才能见
- 单凭眼根（净色根）不能见；单凭眼识也不能见

### 第三颂 · 圣者位转依

**变相观空唯后得**

*白话*：前五识即使到佛果，能观察诸法空性，也不是直接亲证真如——它必须先现起一个「空」的相，再借这个相来观察。所以这种观空属于「后得智」，不是「根本智」。

*术语*：
- **根本无分别智** = 直接亲证真如本身（无相分）—— 第六、第七识转依后可起
- **后得智** = 变现真如的「相分」，通过相分间接观真如 —— 前五识只能起这个
- **变相** = 现起一个「空」的相
- **为什么五识只能后得**：因为五识本质是「现量」（必有实际所缘境），唯自性分别，不能脱开相分直接亲证真如

**果中犹自不诠真**

*白话*：即使到了佛果，前五识转成成所作智之后，也不能直接「诠表」真如——它只能现量感知相分，不能用名言概念把真如表达出来。

*术语*：
- 「果中」= 佛果位
- 「诠」= 用名言概念诠表
- 「真」= 真如
- **五识为什么不能诠真**：因为不能加名言、概念、推理、判断（这些属于第六识的计度分别）

**圆明初发成无漏**

*白话*：前五识第一次「圆满明朗」地起为无漏，就在佛果一刹那（与第八识同时转）。在这之前一直都是有漏。

*术语*：
- 「圆明」= 圆满明朗（佛果圆满无有障碍）
- 「初发」= 第一次起（这之前一直有漏）
- 「无漏」= 断除有漏种子，起心动念全无漏
- **转依时机**：佛果一刹那（与第八识大圆镜智**同时转**）

**三类分身息苦轮**

*白话*：佛果成所作智起化用，化现三类身度众生——大化身、小化身、随类化身；度脱六道众生出离苦海。

*术语*：
- **大化身** = 千丈卢舍那身（为大菩萨显现）
- **小化身** = 释迦丈六身（为凡夫、二乘显现）
- **随类化身** = 应机随类现（如观音三十二应、地藏变现）
- 「息苦轮」= 度脱六道苦海轮回

## 第二章 · 第六识颂

### 第一颂 · 凡夫位基本特征

**三性三量通三境**

*白话*：第六识三性、三量、三境全通——比五识多通两维（量 + 境）。五识只能性境 + 现量；第六识可以缘一切境、起一切量。

*术语*：
- **三性 / 三量 / 三境**：定义见前五识第一句
- **第六识 = 三境三量三性全通**：能力最全
- **三量分工**：**现量** = 五俱意识（跟五识同时缘性境）；**比量** = 正确推理；**非量** = 错误推理
- **三境分工**：**性境** = 五俱意识跟五识同缘色声香味触；**带质境** = 缘他人心 / 自己心的相状；**独影境** = 缘梦、想象、龟毛兔角

**三界轮时易可知**

*白话*：三界九地——欲界、色界四禅、无色界四禅——全都现行第六识。轮回时最活跃、最容易观察。

*术语*：
- **三界九地** = 欲界 1 地 + 色界 4 禅 + 无色界 4 定
- 「轮时」= 三界六道**轮回时**；「易可知」= **最易观察**
- 第六识 独一无二——**三界九地全通**
- **例外——五位无心**：**无想定** / **无想天** / **灭尽定** / **极睡眠** / **极闷绝** 时第六识暂断

**相应心所五十一**

*白话*：51 个心所全部都可以跟第六识相应——是八识里相应最多的。

*术语*：
- **51 心所全应** = 遍行 5 + 别境 5 + 善 11 + 根本烦恼 6 + 随烦恼 20（大 8 + 中 2 + 小 10）+ 不定 4（悔 / 眠 / 寻 / 伺）
- 对比：**前五识 34 / 第六识 51 / 第七识 18 / 第八识 5**
- 为什么第六识 51 全应？—— 具三种分别，计度分别类心所全能起

**善恶临时别配之**

*白话*：具体起善 / 起恶 / 起无记，临时根据缘境决定——不是恒定一种性。

*术语*：
- 「临时」= 当下那一刹那决定
- 「别配」= 按当下缘境、跟相应心所具体搭配决定三性
- **对比第七识**：**恒审思量**——恒起我执，从来不是善，三性**唯有覆无记**（一种到底）

### 第二颂 · 凡夫位造业主

**性界受三恒转易**

*白话*：性、界、受这三样，都恒时变易——第六识从不定在一个状态。「三」修饰前三字，不是「三种受」。

*术语*：
- **「三」修饰前三字**（性、界、受）—— 不是「三种受」
- **性** = 三性（善 / 恶 / 无记）交替
- **界** = 三界（欲界 / 色界 / 无色界）—— 生哪界起哪界
- **受** = **五受**（苦 / 乐 / 忧 / 喜 / 舍）—— 交替变易
- 三受对比：**第六识通 5 受**；前五识 **3 受**（苦 / 乐 / 舍，无忧喜——忧喜是心受，唯第六识有）；第七识**唯舍受**

**根随信等总相连**

*白话*：根本烦恼、随烦恼、善心所（信、精进等）—— 都跟第六识相应。

*术语*：
- 「根」= **6 根本烦恼**（贪 / 嗔 / 痴 / 慢 / 疑 / 不正见）
- 「随」= **20 随烦恼**（大 8 + 中 2 + 小 10）
- 「信等」= **11 善心所**（信 / 精进 / 惭 / 愧 / 无贪 / 无嗔 / 无痴 / 轻安 / 不放逸 / 行舍 / 不害）
- 加遍行 5 + 别境 5 + 不定 4 = **51 心所全部**

**动身发语独为最**

*白话*：三业里的身业（动身）和语业（发语），造业能力第六识最强、独一。

*术语*：
- 「动身」= 引发身业（走、坐、动作）
- 「发语」= 引发语业（说话、辩论）
- 「独为最」= 8 识里**独第六识有这个能力，且最强**
- 为什么只第六识能：前五识被动感知；第七识内缘不外造业；第八识无记不造业
- **意业** = 第六识起心动念本身就是

**引满能招业力牵**

*白话*：第六识造引业 + 满业，两种业力都能招感三界果报。

*术语*：
- **引业**（总报业）= 引导生哪一趣的主业（如造上品十善引生天；造十恶引堕地狱）—— 一期生死的**主报**
- **满业**（别报业）= 决定那一趣内具体差别的业（如同生人道，长寿 / 短寿 / 富贵 / 贫穷 是满业决定）—— 那一趣内的**别报**
- 「能招」= 招感相应果报；「业力牵」= 业力牵引六道轮回

### 第三颂 · 圣者位转依

**发起初心欢喜地**

*白话*：菩萨登初地欢喜地那一刹那——第六识的转依就发起了。

*术语*：
- 「极喜」/「欢喜地」= **初地**
- 「初心」= 见道位那一心（**通达位**）
- 「发起」= **妙观察智初现**（一分无漏无分别智）
- **见道位所断**：**分别我执 / 分别法执** 一时顿断
- 第六识、第七识**转依起点相同**——都在初地就起一分

**俱生犹自现缠眠**

*白话*：登初地后一直到七地，第六识里的俱生烦恼仍然会现行或潜伏（种子）。

*术语*：
- 「俱生」= 与生俱来（对比见道断的**分别起**）
- 「缠」= **现行**（现前显现）
- 「眠」= **种子潜伏**（未现行但有种子）
- **断除时序**（严格分现行 vs 种子）：
  - **俱生我执 · 现行**：二地起渐伏，**七地满**永伏
  - **俱生我执 · 种子**：修道位渐次断灭，**金刚喻定 / 佛果** 才彻底断尽

**远行地后纯无漏**

*白话*：菩萨修到七地远行地之后——第六识才纯无漏（不再起有漏心）。

*术语*：
- 「远行地」= 十地**第七地**
- 「后」= 七地圆满进入**八地**
- 「纯无漏」= 有漏种子已断，起心动念全是无漏
- **八地 = 不动地**（无功用道，任运起妙观察智）

**观察圆明照大千**

*白话*：佛果位妙观察智观察圆满明朗，遍照三千大千世界。

*术语*：
- 「观察」= 妙观察智特质（观察诸法**自共相无碍**）
- 「圆明」= 圆满明朗（佛果圆满无有障碍）
- 「大千」= 三千大千世界
- **说法度生** 是妙观察智独有果用（大圆镜智、平等性智不做这个）

## 第三章 · 第七末那识颂

### 第一颂 · 凡夫位基本特征

**带质有覆通情本**

*白话*：末那唯缘带质境、三性唯有覆无记；「通情本」= 能缘（末那自身）+ 所缘的本质（第八见分）两头都取。

*术语*：
- 「带质」= 三境之一（有真实本质但带上「我」情执）
- 「有覆无记」= 三性之一。**「覆」**= 覆蔽真理；**「无记」**= 非善非恶
- 「情」= 能缘之心（末那自身）；「本」= 所缘本质（第八见分）
- **对比**：前五识唯性境通三性；第六识三境三性全通；末那**唯带质、唯有覆无记**

**随缘执我量为非**

*白话*：末那随所缘境（第八见分）执之为「我」；这个认识是错的，所以三量唯非量。

*术语*：
- 「随缘」= 随所缘境
- 「执我」= 把第八见分（本来是识的**功能**，不是「我」）执为常一的「我」
- 「量为非」= 三量里的**唯非量**（结构性错认，不是偶然认错）
- **对比**：前五识唯现量；第六识三量全通；末那**唯非量**

**八大遍行别境慧**

*白话*：末那相应心所前 14 个—— 8 个大随 + 5 个遍行 + 别境中的慧（只有慧，别境其他 4 个不相应）。

*术语*：
- **大随 8** = 掉举 / 昏沉 / 不信 / 懈怠 / 放逸 / 失念 / 散乱 / 不正知
- **遍行 5** = 触 / 作意 / 受 / 想 / 思
- **别境慧** = 别境 5 中只有**慧**一个
- **为什么别境只有慧**？—— 末那恒时思量必伴随「慧」的抉择；别境其他 4 个（欲 / 胜解 / 念 / 定）跟末那恒执特征不合

**贪痴我见慢相随**

*白话*：末那相应的四烦恼——我贪、我痴、我见、我慢，恒相随、从来不断。

*术语*：
- **四烦恼常俱**（跟末那恒起）：
  - **我痴**（无明）= 不了「我空」的根本无明
  - **我见**（我执）= 执第八见分为「我」
  - **我慢**（傲慢）= 恃「我」而生高下
  - **我爱**（我贪）= 爱着「我」
- **合计 18 心所** = 8 大随 + 5 遍行 + 1 别境慧 + 4 烦恼（比第六识 51 少 33 个）

### 第二颂 · 凡夫位作用

**恒审思量我相随**

*白话*：末那恒时起「思量」——而且思量的对象就是「我」，从来不断。

*术语*：
- **8 识里独末那「恒且审」**：

| 识 | 恒 | 审 | 说明 |
| --- | :-: | :-: | --- |
| 前五识 | ✗ | ✗ | 时起时不起，无深细审察 |
| 第六识 | ✗ | ✓ | 能深细审察，但五位无心时暂断 |
| **第七识** | **✓** | **✓** | 恒时相续，恒执我 |
| 第八识 | ✓ | ✗ | 相续不断，但无审察 |

- 「我相随」= 「我执」恒时相随——末那从来没有「不执我」的一刹那（凡夫位）

**有情日夜镇昏迷**

*白话*：末那我执日夜不断，使一切有情镇日昏迷在「我」中，看不清真相。

*术语*：
- 「日夜」= 白天 / 夜里都不断
- 「镇」= 长时 / 常时
- 「昏迷」= 迷于「我」相中，被我执所蔽
- 深意：这就是「**无始无明**」的深层根源——第六识可以修观暂离我执，但**只要末那不转，我执就永不断根**

**四惑八大相应起**

*白话*：这一句把第一颂讲过的心所再总结——四惑（四烦恼）+ 八大（八大随）跟末那同起同灭。

*术语*：
- 「四惑」= 四烦恼（我痴 / 我见 / 我慢 / 我爱）
- 「八大」= 八大随烦恼
- **承前启后**：重申末那相应 18 心所里的 **12 个染污类**（8 大 + 4 惑），引出下一句「染净依」

**六转呼为染净依**

*白话*：前六识（前五识 + 第六识）叫「六转识」；它们起善 / 起染，依第七识决定——所以第七叫「染净依」。

*术语*：
- 「六转」= 前 5 + 第 6 = **前六转识**
- 「呼为」= 称为；「染净依」= 染净的根据 / 依据
- **运作机制**：末那**起染心** → 前六识起染心（凡夫位）；末那**转清净** → 前六识也净化（圣者位）
- 所以末那又叫「**染污意**」——是六转识染污的**根**

### 第三颂 · 圣者位转依

**极喜初心平等性**

*白话*：菩萨见道后进入修道位的第一心——刚登极喜地（初地）那一刹那，第七识平等性智就一分现起。

*术语*：
- 「极喜」= 极喜地 = **初地欢喜地**
- 「初心」= 见道后进入**修道位**的第一心（不是见道位那一心；严格分：**加行位 → 通达位（见道）→ 修道位（登地）**）
- 「平等性」= 平等性智**一分现前**
- 见道位所断：**分别我执 / 分别法执** 一时顿断；**俱生我执**（末那恒起的那种）还没断——下一句讲

**无功用行我恒摧**

*白话*：菩萨修到八地不动地，进入无功用道——第七识里的俱生我执现行永被摧毁。

*术语*：
- 「无功用行」= 无功用道 = **八地不动地**
- 「我恒摧」= 俱生我执**现行永伏、不再现起**
- **严格分「现行」vs「种子」**：
  - **俱生我执 · 现行**：**八地起**永伏（不再现起）
  - **俱生我执 · 种子**：修道位渐次断灭，**佛果**才彻底断尽
- **八地 = 舍藏识**：因第七不再执第八为「我」，第八识不再叫「阿赖耶」（藏识），只叫「异熟识」

**如来现起他受用**

*白话*：佛果位第七识转成的平等性智起「他受用身」——为登地菩萨显现的殊胜报身。

*术语*：
- **佛的三身**：
  - **自性身**（法身）= 真如
  - **受用身** 分两种：**自受用**（佛自证功德，**大圆镜智** 主）；**他受用**（为登地菩萨显现，**平等性智** 主）
  - **变化身**（化身）= **成所作智** 主
- **他受用身** 是平等性智独有果用

**十地菩萨所被机**

*白话*：他受用身度化的对象是十地菩萨——不度凡夫、不度声闻二乘。二乘虽有见道，但只证人无我，不证法无我，未破法执，感应不了报身。

*术语*：
- 「十地菩萨」= **初地至十地**的登地菩萨
- 「所被机」= 所摄化之根机
- **为什么只度十地菩萨**：
  - 凡夫未见道
  - 二乘虽有见道，但**只证人无我，不证法无我**（未破法执）—— 感应不了他受用身
  - 大乘登地菩萨（初地起）见道**同时证二空**（人空 + 法空），破分别法执，能感应报身
  - 凡夫、二乘 由 **变化身**（成所作智）度化

## 第四章 · 第八阿赖耶识颂

### 第一颂 · 凡夫位基本特征

**性唯无覆五遍行**

*白话*：第八识三性只有无覆无记一种；相应心所也只有 5 个遍行（触、作意、受、想、思）。是八识里相应心所最少的。

*术语*：
- 「无覆」= 不覆蔽真理（对比末那「有覆」）
- 「无记」= 非善非恶
- 「5 遍行」= 触 / 作意 / 受 / 想 / 思（一切心识必伴）
- **为什么只 5 遍行**：第八识体性微细、恒相续、无审察，其他 46 心所特征太粗，跟第八识不合
- 相应心所对比：前五识 34 / 第六识 51 / 第七识 18 / **第八识 5**（最少）

**界地随他业力生**

*白话*：第八识在三界九地随业力招感——「他」= 业力；不能自主选择在哪界哪地。

*术语*：
- 「界地」= **三界九地**（欲界 + 色界 4 禅 + 无色界 4 定）
- 「随他」= 随「他」（业力）而生，不能自主
- 「业力生」= 前生**引业**决定今生生哪一界
- 第八识是**异熟识**——「异熟」= 酬引业招异熟果，专门承受业力果报

**二乘不了因迷执**

*白话*：二乘（声闻、缘觉）不了第八识存在——因为迷执于「六识为主体」的立场。

*术语*：
- 「二乘」= 声闻乘 + 缘觉乘
- 「不了」= 不承认 / 不了解
- 「因迷执」= 因为迷执于「六识为主体」
- **教理立场对比**：**二乘立场** 只讲六识，不立第七、第八；**大乘唯识** 八识全立

**由此能兴论主诤**

*白话*：由此（第八识存在 vs 二乘立场），唯识论主（弥勒、无著、世亲、护法等）兴起论辩，建立阿赖耶识教。

*术语*：
- 「论主」= **唯识论主**（弥勒、无著、世亲、护法 等）
- 「诤」= 论辩、争辩
- **主要论辩点**：
  - 若无第八，**种子**由谁执持？（业力如何相续？）
  - 若无第八，**生死主体**是谁？
  - 若无第八，**根身 / 器界**由谁相续执持？
- 论主用**十种理由**证明第八识必存在（详见《成唯识论》卷 3）

### 第二颂 · 凡夫位作用

**浩浩三藏不可穷**

*白话*：第八识「浩浩」如大海，含三藏义——能藏 / 所藏 / 执藏，深不可穷。

*术语*：
- **三藏义**：
  - **能藏** = 能含藏一切种子（种子的仓库）
  - **所藏** = 被前七识熏习（种子的容器）
  - **执藏** = 被第七识执为「我」（跟末那的关系）
- 「浩浩」= 广大无边；「不可穷」= 深广无尽
- **「执藏」是「阿赖耶」得名的关键** —— 八地起舍执藏，就叫「舍藏识」

**渊深七浪境为风**

*白话*：第八识深如渊；前七识如七浪；所缘境如风（吹起浪）。前七识依阿赖耶而起，如浪起于海——这就是「万法唯识」的深意。

*术语*：
- 「渊深」= 阿赖耶深不可测（如海）
- 「七浪」= 前七识（前五 + 六 + 七）如七种波浪
- 「境为风」= 所缘境如风，吹动波浪起
- **概括「万法唯识」根本原理**：前七识依第八识而起（如浪起于海）

**受熏持种根身器**

*白话*：第八识四大功能——受熏（受前七识熏习）/ 持种（执持一切种子）/ 执持根身 / 执持器世间。

*术语*：
- **四大功能**：
  - **受熏** = 接受前七识（现行）的熏习，转成种子
  - **持种** = 执持一切种子不失（善恶业种、名言种）
  - **根身** = 执持有情的**有根身**（净色五根 + 肉体扶尘根）
  - **器** = 执持**器世间**（山河大地、无情世界）
- **受熏 + 持种** 是种子论核心；**根身 + 器** 是唯识对世界的解释——这就是「**三界唯心**」

**去后来先作主公**

*白话*：死时最后离（去后）、生时最先来（来先）——第八识是生死轮回的主体（「主公」= 主人翁）。

*术语*：
- **去后** = 死亡时，前七识先散灭；**第八识最后离身**（体温最后冷）
- **来先** = 受胎时，**第八识最先来结生**（然后其他七识渐次现起）
- 「作主公」= 是生死轮回的主人翁
- **佛教「不断灭、不常有」**：第八识**相续不断**但**刹那生灭**（既非断灭也非常一）

### 第三颂 · 圣者位转依

**不动地前才舍藏**

*白话*：菩萨修到不动地（八地）之前——七地末那一刹那，第八识舍「藏识」名（因第七识不再执之为我）。舍藏后叫「异熟识」。

*术语*：
- 「不动地」= 十地**第八地**
- 「前才舍藏」= 八地之前那一刹那（**七地末进入八地时**）舍「藏识」名
- 「舍藏」= 舍「阿赖耶」名（三藏义中「**执藏**」义舍）
- **原因**：第七识**俱生我执现行永伏**，不再执第八为「我」，「执藏」义舍
- **舍藏后叫**：**异熟识**（仍有异熟义，酬引业招果报）

**金刚道后异熟空**

*白话*：菩萨修到金刚喻定（十地末等觉最后一刹那）之后——「异熟识」名也空掉（有漏种子全断尽）。舍异熟后叫「无垢识」。

*术语*：
- 「金刚道」= **金刚喻定** = 十地末等觉位最后一刹那**无间道定**
- 「后」= 金刚喻定之后 = **佛果一刹那**
- 「异熟空」= 「异熟识」这个名也舍
- **原因**：所有**有漏种子**（含引业种子）**全断尽**，不再有「异熟果」
- **舍异熟后叫**：**无垢识**（一切有漏皆断，唯余无漏）
- **三个名字对应三个阶段**：阿赖耶（凡夫至七地末）→ 异熟识（八地至金刚道）→ 无垢识（佛果）

**大圆无垢同时发**

*白话*：佛果一刹那——第八识转成的大圆镜智（智）+ 无垢识（识）同时现起，跟前五识转成的成所作智同时（都是佛果一刹那）。

*术语*：
- 「大圆」= **大圆镜智**
- 「无垢」= **无垢识** = 佛果位第八识的名字
- 「同时发」= 智 + 识同时现起（一齐转成）
- **大圆镜智 vs 无垢识 关系**：**同体异名**（智是能证、识是所依）
- **大圆镜智** 跟 **成所作智**（前五识转）**同时起**——都是佛果一刹那

**普照十方尘刹中**

*白话*：大圆镜智遍照十方无量佛土——像大圆镜映现一切。大圆镜智主司自性身（法身）+ 自受用报身 + 持无漏种。

*术语*：
- 「普照」= 大圆镜智遍照
- 「十方尘刹」= 十方无量佛土（微尘般多）
- **大圆镜智果用**：
  - **现自性身**（法身）+ **自受用报身**
  - **持无漏种**（跟凡夫位持一切种不同）
  - 映现一切法（如大圆镜）
- **四智分工**：大圆镜智**主自受用**；平等性智**主他受用**；妙观察智**主说法度生**；成所作智**主现三类化身**
