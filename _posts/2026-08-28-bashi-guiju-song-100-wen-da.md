## 一、前五识颂（1–25）

### 第一颂：性境现量通三性 / 眼耳身三二地居 / 遍行别境善十一 / 中二大八贪嗔痴

#### 1. 为什么前五识是三境中的「性境」？

三境（性境 / 带质境 / 独影境）里，性境 = 真实存在的境，直接感知，不带概念执取。前五识只缘色声香味触五尘本身，不加名言、不做推理，所以唯性境。带质境（如末那缘第八见分执为我）、独影境（如梦、想象、龟毛兔角）都要意识介入，五识没有这个能力。

#### 2. 为什么前五识是三量中的「现量」？

三量里，现量 = 当下直接感知，没有名言分别；比量 = 通过推理得到的正确认识；非量 = 错误的认识。前五识只做「感知」这一步，不做「推理」也不「判断对错」，所以唯现量。「推理判断」是第六识的计度分别，五识没有。

#### 3. 为什么前五识「通三性」（三性是哪三性？）？

三性 = 善 / 恶 / 无记（非善非恶）。前五识自体不分别善恶，但可以随缘起善、起恶、起无记——具体善恶由**心所搭配 + 第六识引发**共同决定。第六识起善心，五识跟着起善；第六识起染心，五识跟着染。

#### 4. 为什么色界二禅以上前五识全部停？

前五识只在「有寻有伺地」（欲界 + 色界初禅）起。二禅以上是「无寻无伺地」，禅定深了，粗重的感官境已经离开，前五识没有生起的因缘，全部停息。定中的心是靠第六识缘内境，不用五识。

#### 5. 为什么鼻识、舌识只在欲界起（色界初禅都没有）？

色界众生已经离「段食欲」——不需要物质食物、也没有食物的香味。所以色界连初禅都没有鼻识、舌识的对境（香、味），只保留眼识、耳识、身识三个。这就是颂文「眼耳身三」的意思。

#### 6. 为什么跟前五识相应的善 / 中性心所是 21 个（是哪 21 个？）？

21 个 = 遍行 5 个（触 / 作意 / 受 / 想 / 思，一切心识必伴）+ 别境 5 个（欲 / 胜解 / 念 / 定 / 慧）+ 善 11 个（信 / 精进 / 惭 / 愧 / 无贪 / 无嗔 / 无痴 / 轻安 / 不放逸 / 行舍 / 不害）。这是善心起时可能相应的最大范围（不一定同时都起）。

#### 7. 为什么「小随烦恼」10 个不跟前五识相应？

小随 10（忿 / 恨 / 覆 / 恼 / 嫉 / 悭 / 诳 / 谄 / 害 / 憍）「行相猛利，唯各别起」——都是第六识计度分别心起的复杂烦恼，需要「回忆、比较、构想」等意识活动，前五识只有自性分别，起不了这些。

#### 8. 为什么根本烦恼里的「慢、疑、不正见」不跟前五识相应？

慢 = 比较高下；疑 = 怀疑真理；不正见 = 错误见解——都要**计度分别**判断。前五识只有自性分别（直接感知），不能做判断、推理、比较，所以起不了这三个。跟前五识相应的根本烦恼只有贪、嗔、痴 3 个。

#### 9. 为什么跟前五识相应的染污心所只有 13 个？

13 个 = 中随 2（无惭 / 无愧）+ 大随 8（掉举 / 昏沉 / 不信 / 懈怠 / 放逸 / 失念 / 散乱 / 不正知）+ 根本 3（贪 / 嗔 / 痴）。不相应的：小随 10 + 慢/疑/不正见 3 + 不定 4 = 17 个，加上 34 = 51 个心所（跟第六识对比缺 17）。

### 第二颂：五识同依净色根 / 九缘八七好相邻 / 合三离二观尘世 / 愚者难分识与根

#### 10. 为什么前五识依「净色根」而不是「扶尘根」？

净色根 = 五根的**体性**，是极微细的净色，才是真正让五识起「了别」作用的根。扶尘根 = 肉团根（眼球、耳廓等），只是净色根的**载体**，本身没有认识能力。剖开眼球找不到「能看」的东西，因为「能看」的是背后的净色根 + 眼识。

#### 11. 什么是净色根？跟扶尘根有什么区别？

从现代角度理解：扶尘根 ≈ 肉眼可见的感官器官（眼球、耳廓、鼻孔、舌头、身体表面）；净色根 ≈ 整个感官机制的精微部分（如眼根 = 眼球 + 视网膜 + 视神经 + 视觉中枢一整套）。缺了净色根，扶尘根形状再完整也不能起识（如死人）。

#### 12. 为什么眼识要 9 个缘才能生起（是哪 9 个）？

9 缘 = 空（距离）/ 明（光明）/ 根（净色根）/ 境（所缘色境）/ 作意（作意心所引发）/ 分别依（第六意识）/ 染净依（第七末那识）/ 根本依（第八阿赖耶识）/ 种子（自识种子）。缺一不能起。「分别依 / 染净依 / 根本依」= 六 / 七 / 八识作为俱有依，反映八识相互依止。

#### 13. 为什么耳识只要 8 个缘（少了「明」）？

耳识少「明」——黑暗中也能闻声，声音传播不依赖光明。其他 8 个缘（空 / 根 / 境 / 作意 / 分别依 / 染净依 / 根本依 / 种子）都跟眼识一样。

#### 14. 为什么鼻舌身识只要 7 个缘（少了「空 + 明」）？

鼻舌身识是「合中取」——所缘境必须直接接触根才能起识（闻香、尝味、触觉），不需要空间距离，也不需要光明。所以少「空」+「明」两个缘。

#### 15. 为什么眼识、耳识是「离中取」？

眼识、耳识的所缘境要跟根之间**保持距离**才能起识——眼球贴到物体上就看不见，耳朵贴到声源上反而听不清。距离（空）是它们必要的缘之一。

#### 16. 为什么鼻舌身识是「合中知」？

鼻舌身识必须让所缘境跟根**接触**才能起识——香气要飘到鼻孔、味道要接触舌头、触觉要碰到身体。它们不能「远距离感知」（这跟眼耳不同）。

#### 17. 为什么凡夫容易混淆「识」跟「根」？

凡夫看见东西时，直觉就说「是眼睛看见的」——把「能看」归给眼睛（肉团根 / 扶尘根）。实际上是「眼识 + 眼根 + 色境 + 作意 + 种子 + 六七八识作俱有依」等多缘合力才能见。单凭眼根不能见（死人有眼），单凭眼识也不能见（要多缘）。凡夫看不清这个「多缘合力」的机制。

#### 18. 为什么单凭净色根不能见？

净色根是五识的**依止**，不是能见者本身。能见的是「眼识」这个心识。净色根 + 眼识 + 色境 + 作意 + 六七八识作俱有依 + 种子——**九缘合力**才能生起「见」。缺少眼识（如深睡时净色根还在但意识断了），就见不了。

### 第三颂：变相观空唯后得 / 果中犹自不诠真 / 圆明初发成无漏 / 三类分身息苦轮

#### 19. 为什么前五识转成成所作智只能起「后得智」，不能起「根本智」？

根本无分别智 = 直接亲证真如本身（无相分）；后得智 = 变现真如的「相分」间接观察。第六识、第七识具计度分别，可以「舍相直取」真如，起根本智。前五识本质是「现量」，必有实际所缘境（相分），无法脱开相分直接亲证真如——所以只能起后得智。

#### 20. 什么是根本无分别智？什么是后得智？

根本无分别智 = 无分别智，直接亲证真如本身，无相分中介（第六识、第七识转依后能起）。后得智 = 从根本智出观后所得的智，通过变现真如的相分间接观察诸法（四智都通后得；前五识、第八识主要起后得）。

#### 21. 为什么前五识要「变相观空」？

前五识唯自性分别，唯现量，必有相分才能缘。它不能像根本智那样直接亲证真如（真如无相分）。所以佛果位前五识观诸法空性时，必须**先变现一个「空」的相分**，再借这个相分间接观察真如——这就叫「变相观空」，唯后得智。

#### 22. 为什么即使到佛果，前五识也「不诠真」？

「诠」= 用名言概念诠表。前五识只做直接感知（现量），不能加名言、概念、推理、判断（这些属于第六识的计度分别）。即使转成成所作智，果用还是「现三类化身度众生」，用名言诠表真如 是妙观察智的功能，不是成所作智的。

#### 23. 为什么前五识的转依要到佛果一刹那才发起？

前五识本质是现量、唯自性分别、被动感知，一定要 8 个转识里最深的第八识 先转（大圆镜智），前五识才能同时转成所作智。所以佛果前一直有漏，佛果一刹那才第一次「圆明」起为无漏。这跟第六、第七识初地就起一分完全不同。

#### 24. 为什么前五识第一次「圆明」就成无漏？

「圆明」= 圆满明朗（佛果圆满无有障碍）。前五识在这之前一直有漏，佛果一刹那是「一齐转」的最后一环——大圆镜智 + 成所作智 + 无垢识同时发起。「初发」就是圆满，没有渐修的中间阶段。

#### 25. 为什么大化身、小化身、随类化身叫「三类分身」？

佛果位前五识转成成所作智，它的果用就是「化现身相度众生」。**大化身** = 千丈卢舍那身（为大菩萨显现）；**小化身** = 释迦丈六身（为凡夫、二乘显现）；**随类化身** = 应机随类现（如观音三十二应、地藏变现）。三类化身能度尽六道，「息苦轮」= 度脱轮回苦海。

## 二、第六识颂（26–50）

### 第一颂：三性三量通三境 / 三界轮时易可知 / 相应心所五十一 / 善恶临时别配之

#### 26. 为什么第六识可以「三性三量三境全通」？

第六识具**三种分别**（自性 + 计度 + 随念），是八识里唯一三种分别全有的识。所以三性全通（善 / 恶 / 无记都能起）、三量全通（现量 / 比量 / 非量都能起）、三境全通（性境 / 带质境 / 独影境都能缘）——能力最全。前五识只有自性分别，只能唯性境、唯现量。

#### 27. 为什么第六识比前五识多通两个维度（量 + 境）？

前五识唯性境唯现量，因为它只做「直接感知真实五尘」这一步。第六识多了计度分别和随念分别——所以可以起比量（推理）、非量（错认）；可以缘带质境（缘他心 / 自心）、独影境（缘梦 / 想象 / 龟毛兔角）。多的两维就是「量 + 境」两个维度全通。

#### 28. 为什么第六识可以在「三界九地」全部现行？

第六识是「意识」，不受禅定深浅限制。前五识在二禅以上就停（无寻无伺，粗尘境离），只有第六识能在欲界 + 色界四禅 + 无色界四定共九地全部现行。所以「三界轮时易可知」——三界轮回时最活跃、最容易观察。

#### 29. 什么是「五位无心」？第六识为什么在这时暂断？

五位无心 = **无想定 / 无想天 / 灭尽定 / 极睡眠 / 极闷绝**。这五种状态下第六识（连同前六识）暂时不起。除了这五位，第六识在三界九地一直现行。「五位无心」是第六识唯一的例外，不是常态。

#### 30. 为什么第六识可以跟 51 个心所全部相应？

51 心所 = 遍行 5 + 别境 5 + 善 11 + 根本烦恼 6 + 随烦恼 20 + 不定 4，就是《百法明门论》里心所法全部。第六识具**计度分别**，凡是需要「推理、判断、比较」才能起的心所（小随 10 / 慢 / 疑 / 不正见 / 不定 4 等）都能起，所以 51 个心所全应。前五识缺计度分别，只 34 个。

#### 31. 为什么第六识「起善 / 起恶 / 起无记」是「临时别配」？

「临时」= 当下那一刹那决定；「别配」= 按当下缘境、跟相应心所具体搭配。第六识本身不是恒善也不是恒恶，是**灵活多变的**——见佛像起敬心（善）、见仇人起嗔心（恶）、见风景无所思（无记）。对比第七识：**恒审思量恒起我执**，三性唯有覆无记，一种到底，从不变。

### 第二颂：性界受三恒转易 / 根随信等总相连 / 动身发语独为最 / 引满能招业力牵

#### 32. 为什么颂文说「性界受三」，「三」不是「三种受」？

「三」修饰前三字（性、界、受），意思是「性、界、受这三样都恒时变易」，**不是「三种受」**（那样五受就变三受了）。性 = 三性交替；界 = 三界交替（生哪界起哪界）；受 = 五受（苦乐忧喜舍）交替。三样都变——所以第六识从不定在一个状态。

#### 33. 为什么第六识通「五受」而前五识只通「三受」？

第六识通**五受**：苦 / 乐 / 忧 / 喜 / 舍。前五识只通**三受**（苦 / 乐 / 舍），因为「忧」跟「喜」是**心受**（心理层面的受），只有第六意识有；前五识只有「身受」（生理层面），忧喜起不了。第七识**唯舍受**——恒起我执但不苦不乐。

#### 34. 为什么根本烦恼、随烦恼、善心所全都跟第六识相应？

因为第六识 51 心所全通。「根」= 6 根本烦恼（贪 / 嗔 / 痴 / 慢 / 疑 / 不正见），全应；「随」= 20 随烦恼（大 8 + 中 2 + 小 10），全应；「信等」= 11 善心所（信、精进、惭、愧、无贪、无嗔、无痴、轻安、不放逸、行舍、不害），全应。加遍行 5 + 别境 5 + 不定 4 = 51。

#### 35. 为什么「动身发语」独第六识最强？

三业（身业 / 语业 / 意业）里，身业和语业都要靠**意识引发**——想动才动、想说才说。前五识只是被动感知，不能主动引发行动；第七识只内缘第八识见分（恒执我），不外造业；第八识无记藏识，不造业。所以引发身、语造作的能力，「独第六识有，且最强」。

#### 36. 为什么前五识、第七识、第八识都不能造「身、语业」？

**前五识**：只做当下的直接感知，被动缘境，不能主动引发行动。**第七识**：只内缘第八识见分，恒起我执，不参与外部造业。**第八识**：无覆无记的藏识，只是种子仓库，不主动造业。所以「意业为主，导引身语」——身语业都要由第六识（意业）引发。

#### 37. 什么是「引业」跟「满业」？为什么都要靠第六识？

**引业**（总报业）= 引导生哪一趣的主业（如造上品十善引生天，造十恶引堕地狱）——决定「生哪一趣」。**满业**（别报业）= 决定那一趣内具体差别（如同生人道，长寿 / 短寿 / 富贵 / 贫穷）——决定「趣内的差别」。两种业力都是第六识造的，所以「引满能招业力牵」。

### 第三颂：发起初心欢喜地 / 俱生犹自现缠眠 / 远行地后纯无漏 / 观察圆明照大千

#### 38. 为什么第六识的转依起点是「初地初心」？

严格分三位：加行位 → 通达位（见道）→ 修道位（登地）。「初心」= 见道后进入**修道位**的第一心（也叫「初地入心」）。菩萨在这一刹那，第六识的**妙观察智一分现前**，同时**分别我执 + 分别法执**顿断。第六识、第七识转依起点相同——都在初地初心起一分。

#### 39. 什么是「见道」？为什么见道能顿断「分别惑」？

见道 = 亲证二空真如（人空 + 法空）那一刹那，属于**通达位**（介于加行位跟修道位之间）。见道位所断 = **分别我执 / 分别法执**——这两种烦恼是「后天分别计度」起的，见到真如时一时顿断（不需要长时渐修）。俱生烦恼是与生俱来的深细执着，见道位断不了，要修道位长时渐断。

#### 40. 为什么「初心」是见道后进入修道位的第一心，不是见道位那一心？

严格分三位：加行位（暖顶忍世第一法）→ 通达位（见道一刹那）→ 修道位（登地起）。见道属**通达位**，见道之后才**登初地**（进入修道位第一地）。「极喜地初心」就是刚登初地的那一刹那，是修道位第一心。见道位本身是通达位，不属于十地。

#### 41. 什么是「俱生烦恼」跟「分别烦恼」？

**分别烦恼**（分别起）= 后天由错误师教、错误思维引起的烦恼——见道时一刹那顿断。**俱生烦恼**（俱生起）= 与生俱来、深细执着的烦恼——修道位长时渐断。第六识里的俱生我执从二地起渐伏，七地满永伏；俱生法执八地起渐伏，佛果才断尽。

#### 42. 为什么俱生烦恼要分「现行」跟「种子」两层来断？

「缠」= 现行（现前显现）；「眠」= 种子（潜伏未起但有种子）。断除时序：**俱生我执 · 现行** 二地起渐伏，七地满永伏；**俱生我执 · 种子** 修道位渐次断灭，金刚喻定 / 佛果 才彻底断尽。所以「远行地后纯无漏」讲的是现行永伏；佛果才是种子断尽。

#### 43. 为什么第六识要到「七地末」才纯无漏？

菩萨修到「远行地」（十地第七地）圆满，俱生我执的现行永伏；进入八地（不动地）就是「无功用道」——**第六识起心动念全无漏**，不再夹杂有漏心。之前一至七地是有漏无漏交杂，八地起才纯无漏。这是转依的一个关键分界点。

#### 44. 什么是「不动地」？为什么八地叫无功用道？

「不动地」= 十地第八地（远行地之后）。「无功用道」= 不用刻意用力，任运（自然而然）起妙观察智。之前一至七地是「有相加行位」（要用功），八地起是「无相加行位 → 无功用道」——起心动念全是无漏，任运自在。

#### 45. 为什么妙观察智「说法度生」是它独有的果用？

四智分工：**大圆镜智**主自受用（佛自证）；**平等性智**主他受用身（度十地菩萨）；**妙观察智**主**观察诸法自共相 + 说法断疑**（度一切众生）；**成所作智**主现三类化身。「说法度生」这个功能，大圆镜智、平等性智都不做，唯独妙观察智——因为它「观察自共相」的能力最强，能观机说法。

#### 46. 为什么妙观察智叫「观察圆明照大千」？

「观察」= 观察诸法自相 + 共相无碍（妙观察智的特质）；「圆明」= 圆满明朗（佛果无碍）；「照大千」= 遍照三千大千世界。妙观察智在佛果位圆满，能观机说法，令诸有情断疑生信，度化一切众生。这是妙观察智的最终果用。

## 三、第七末那识颂（47–72）

### 第一颂：带质有覆通情本 / 随缘执我量为非 / 八大遍行别境慧 / 贪痴我见慢相随

#### 47. 为什么第七识唯缘「带质境」？

末那识恒时缘第八识的**见分**，把它执为「我」。第八识见分是真实的（有本质），但末那加上了「我」的情执——这就是**带质境**（有真实本质 + 带一层概念执取）。末那不能缘性境（那是五识+六识），也不能缘独影境（那是六识独变），所以唯带质境。

#### 48. 什么是「带质境」？为什么末那的带质境「通情本」？

带质境 = 有真实本质但带一层概念执取。末那的带质境「通情本」——「情」= 能缘之心（末那自身），「本」= 所缘本质（第八见分），两头都取。既有心一边（末那能缘的情执），又有境一边（第八所缘的本质）。所以叫「通情本」。

#### 49. 为什么第七识唯「有覆无记」性？

「覆」= 覆蔽真理（末那恒起我执，蔽真如）；「无记」= 非善非恶。末那的我执深细恒转，不是明显造恶（不像贪嗔），也不是善——所以是**有覆无记**。而且末那从不变——不像第六识临时别配三性。前五识、第六识通三性；第八识唯无覆无记；第七识唯有覆无记。

#### 50. 为什么第七识唯「非量」（错认）？

三量：现量 / 比量 / 非量。末那恒把第八识见分（本来是识的**功能**，不是「我」）执为常一不变的「我」——这是**结构性的错认**，不是偶然认错。所以三量里唯非量。前五识唯现量；第六识三量全通；末那唯非量。

#### 51. 为什么第七识只跟 18 个心所相应？

18 = 大随 8 + 遍行 5 + 别境慧 1 + 四烦恼 4。大随 8（掉举、昏沉、不信、懈怠、放逸、失念、散乱、不正知）—— 末那深细恒转，跟大随相应；遍行 5 —— 一切心识必伴；别境慧 —— 恒审思量必伴慧的抉择；四烦恼 —— 我贪 / 我痴 / 我见 / 我慢。比第六识 51 个少 33 个。

#### 52. 为什么末那相应的别境只有「慧」一个？

别境 5 = 欲 / 胜解 / 念 / 定 / 慧。末那恒时思量执我，必然伴随「慧」的抉择（不然思量不下去）。但其他 4 个跟末那恒执的特征不合：**欲** = 对未来境的希求（末那不缘未来）；**胜解** = 明确判断（末那的执我不是明确判断）；**念** = 明记忆持（末那不追忆）；**定** = 专注一境（末那恒动不定）。所以只有慧一个。

#### 53. 什么是「四烦恼常俱」？为什么它们恒相随？

四烦恼 = **我痴**（无明，不了我空）+ **我见**（我执，执第八见分为我）+ **我慢**（傲慢，恃我而生高下）+ **我爱**（我贪，爱着我）。这四个跟末那**恒起同灭**——末那起时四烦恼也起，从来不断。所以叫「常俱」——不是有时相应，是恒时相应，凡夫位从不间断。

### 第二颂：恒审思量我相随 / 有情日夜镇昏迷 / 四惑八大相应起 / 六转呼为染净依

#### 54. 为什么八识里独末那「恒且审」？

**恒** = 相续不断；**审** = 深细审察。八识里：**前五识** 非恒非审（时起时不起，无深细审察）；**第六识** 审但非恒（审察但五位无心时暂断）；**第七识** 恒且审（本讲主角）；**第八识** 恒但非审（相续但无审察）。只有末那**又相续不断又深细审察**——所以「恒审思量」是它独有的特征。

#### 55. 为什么前五识「非恒非审」？

**非恒** = 时起时不起——眼识需要 9 缘，缺一不起；睡眠、定中五识都不起。**非审** = 只做直接感知（现量），不做深细的审察思量。所以前五识既不恒也不审。

#### 56. 为什么第六识「审但非恒」？

**审** = 具计度分别，能深细审察、推理判断。**非恒** = 五位无心（无想定 / 无想天 / 灭尽定 / 极睡眠 / 极闷绝）时暂断——不是相续不断的。所以第六识审但非恒。

#### 57. 为什么第八识「恒但非审」？

**恒** = 相续不断（凡夫至佛果都相续不断）。**非审** = 只有自性分别（跟前五识一样），不做审察推理——只是「藏识」，含种子、执根身器界，不主动做认识判断。所以第八识恒但非审。

#### 58. 为什么末那使有情「日夜镇昏迷」？

「日夜」= 白天夜里都不断；「镇」= 长时 / 常时；「昏迷」= 迷于「我」中被我执所蔽。末那我执**从来不断**——凡夫连深睡时都在执我。这就是「无始无明」的深层根源。第六识可以修观暂时压伏我执，但只要末那不转，我执**永不断根**。

#### 59. 为什么末那被叫「染污意」？

末那恒起**四烦恼**（我痴、我见、我慢、我爱），并且**染污前六识**——末那染，前六起善也带染；末那清净，前六才能真正净化。它是前六识起善起染的**根本依据**（染净依），也是我执的**根**——所以又叫「染污意」（跟「意识」的「意」区分开）。

#### 60. 为什么前六识的染净都要「依」第七识？

前六识（前五 + 第六）叫「六转识」——它们的染净都要**依**第七识决定：末那起染心 → 前六识起染心（凡夫位）；末那转清净 → 前六识也净化（圣者位）。所以第七叫「**染净依**」——是六转识染净的根据。要转前六识，先要转末那。

### 第三颂：极喜初心平等性 / 无功用行我恒摧 / 如来现起他受用 / 十地菩萨所被机

#### 61. 为什么末那的转依起点是「极喜初心」（跟第六识同时）？

「极喜地」= 初地欢喜地；「初心」= 见道后进入修道位的第一心。菩萨在这一刹那，第七识的**平等性智一分现起**，同时**分别我执**顿断。这跟第六识妙观察智初现是**同一时点**——所以第六识、第七识转依起点相同，都在初地初心起一分。

#### 62. 为什么八地是「无功用行 我恒摧」的关键？

「无功用行」= 无功用道 = 八地不动地。菩萨修到八地进入无功用道，第七识里的**俱生我执现行永被摧毁**——不再现起。这是转依的一个大突破。之前一至七地俱生我执现行相续（虽然见道时分别我执已断），八地才「我恒摧」（永伏）。

#### 63. 什么是「舍藏识」？为什么八地起要舍？

「舍藏」= 舍第八识的「藏识」名（阿赖耶名）。**原因**：八地起第七识**俱生我执现行永伏**，不再执第八见分为「我」——三藏义中「**执藏**」义舍。既然不再被执为我，第八识就不再叫「阿赖耶」（藏识），只叫「异熟识」（仍有异熟义，酬引业招果报）。

#### 64. 为什么俱生我执要分「现行」（八地永伏）跟「种子」（佛果断尽）两层？

严格分：**现行** = 当前起用；**种子** = 潜伏未起但有种子。断除时序：**俱生我执 · 现行** 八地起永伏（不再现起）；**俱生我执 · 种子** 修道位渐次断灭，佛果才彻底断尽。所以「无功用行我恒摧」讲的是现行永伏；种子要到佛果金刚道后才空。

#### 65. 什么是「他受用身」？为什么由平等性智主司？

**佛的三身**：**自性身** = 法身（真如）；**受用身** = 报身（自受用 主由大圆镜智；**他受用** 主由平等性智）；**变化身** = 化身（主由成所作智）。**他受用身** = 为登地菩萨显现的殊胜报身——是平等性智**独有**的果用。大圆镜智主自受用（佛自证），成所作智主变化身。

#### 66. 佛的三身（自性身 / 受用身 / 变化身）跟四智怎么分工？

- **自性身**（法身，真如）= 大圆镜智相应净识显现
- **受用身 · 自受用**（佛自证功德报身）= 大圆镜智变现
- **受用身 · 他受用**（为登地菩萨显现的报身）= **平等性智**变现
- **变化身**（化身，度凡夫二乘的化现）= 成所作智变现
- **妙观察智** = 说法度生（配合前面几身度化）

#### 67. 为什么他受用身只度「十地菩萨」？

他受用身是**佛证二空后**（人空 + 法空）化现的殊胜报身。**十地菩萨**（初地至十地）见道时同时证二空，破分别法执——**能感应报身**。凡夫未见道；二乘虽有见道，但**只证人无我不证法无我**（未破法执）——都感应不了他受用身。凡夫、二乘由变化身（成所作智）度化。

#### 68. 为什么二乘不能感应他受用身？

二乘（声闻 / 缘觉）虽然有见道，但见道时**只证人无我**（我空），**不证法无我**（法空）——所以只破人我执，**未破法执**。他受用身是佛证二空后化现的报身，需要「破法执」的能力才能感应。二乘只破人我执，感应不了他受用身，只能由变化身（成所作智）度化。

## 四、第八阿赖耶识颂（69–94）

### 第一颂：性唯无覆五遍行 / 界地随他业力生 / 二乘不了因迷执 / 由此能兴论主诤

#### 69. 为什么第八识三性唯「无覆无记」？

「无覆」= 不覆蔽真理（对比末那「有覆」——末那有我执覆真理）；「无记」= 非善非恶。第八识是**藏识**，只做「持种、执根身器界」这些微细任运的功能，本身不起善恶（没有推理判断），不覆真理（没有我执）——所以唯无覆无记。

#### 70. 为什么第八识只有 5 个遍行相应（八识里最少）？

第八识体性**微细、恒相续、无审察**——只有 5 个遍行（触 / 作意 / 受 / 想 / 思）跟这种体性合。其他 46 心所都太粗（如别境要专注、善心所要用心、烦恼要审察分别），跟第八识的微细任运不合。相应对比：前五识 34 / 第六识 51 / 第七识 18 / **第八识 5**（最少）。

#### 71. 为什么第八识跟其他 46 个心所都不相应？

第八识的体性是**微细任运、恒相续、无审察**。别境（要专注）、善心所（要用心）、烦恼（要审察分别）、随烦恼（要活跃扰动）、不定（悔 / 眠 / 寻 / 伺要意识活动）——都跟这种体性**不合**。所以除 5 遍行外全部不相应。

#### 72. 为什么第八识「随他业力生」，不能自主？

「他」= 业力（不是他人）。第八识是**异熟识**，专门承受业力果报——前生造的**引业**决定今生生哪一界哪一地。它不能自主选择（造上品十善引生天，造十恶引堕地狱）。所以「界地随他业力生」——第八识随业力招感三界九地果报。

#### 73. 什么是「异熟识」？为什么第八识叫这个名？

「异熟」= 酬引业招异熟果（不同类而熟，如善业成乐果、恶业成苦果）。第八识专门承受业力果报——所以叫「异熟识」。它是第八识的**第二个名字**（对应八地至金刚道阶段）。凡夫至七地末叫「阿赖耶识」；八地起叫「异熟识」；佛果叫「无垢识」。

#### 74. 为什么二乘不承认第八识？

二乘（声闻 / 缘觉）只承认前六识，不立第七、第八——他们的教理体系「只讲六识为主体」。因为对第八识**没有教证 + 迷执于六识为主体**，所以不承认阿赖耶。大乘唯识论主（弥勒、无著、世亲、护法等）用十种理由证明第八识必存在——「由此能兴论主诤」就是讲这个分歧。

#### 75. 唯识论主怎么用「十种理由」证明第八识必存在？

《成唯识论》卷 3 用**十种理由**（十证）证明第八识：如「持种证」（种子由谁执持？）、「异熟证」（业力如何相续？）、「界趣生体证」（生死主体是谁？）、「有色根身证」（根身由谁执持？）、「有情流转证」等。若无第八，种子、业力相续、根身器界执持、生死流转都没法安立——所以必立第八识。

### 第二颂：浩浩三藏不可穷 / 渊深七浪境为风 / 受熏持种根身器 / 去后来先作主公

#### 76. 什么是「浩浩三藏」（能藏 / 所藏 / 执藏）？

第八识「浩浩」如大海，含**三藏义**：**能藏** = 能含藏一切种子（种子的仓库）；**所藏** = 被前七识熏习（种子的容器，接收熏习）；**执藏** = 被第七识执为「我」（跟末那的关系）。三藏义并起，所以叫「阿赖耶」（藏）。

#### 77. 为什么「执藏」是「阿赖耶」得名的关键？

三藏义里，**「执藏」是「阿赖耶」得名的关键**——因为末那恒执第八见分为「我」，第八识才叫「藏识」。八地起，末那**俱生我执现行永伏**，不再执第八为「我」——「执藏」义舍，第八识就不再叫「阿赖耶」，改叫「异熟识」。这就是「舍藏识」的深层机制。

#### 78. 为什么八地舍执藏就叫「舍藏识」？

八地起第七识**俱生我执现行永伏**——不再执第八见分为「我」，「**执藏**」义舍。三藏义里能藏（含种）、所藏（受熏）还在，只有执藏舍。第八识不再叫「阿赖耶」（藏），只叫「异熟识」。这就是「舍藏识」——舍的是**名**（阿赖耶名），不是**体**（第八识本体不断）。

#### 79. 「渊深七浪境为风」这句怎么理解？

**渊深** = 阿赖耶深不可测（如海）；**七浪** = 前七识（前五识 + 第六 + 第七）如七种波浪；**境为风** = 所缘境如风，吹动波浪起。意思：**前七识依阿赖耶而起**（如浪起于海），境界为缘（风），才有波浪。这就是「万法唯识」——前七识都依第八识而起。

#### 80. 为什么这句话概括了「万法唯识」的根本原理？

前七识（万法的能缘）都**依**第八识而起，就像波浪依海而起。境界是「风」（缘），阿赖耶是「海」（体），前七识是「浪」（用）。所有前七识现行的种子存在第八识里，起用时从第八识出来——这就是「万法（前七识）依第八而有」，也就是「万法唯识」的深层根据。

#### 81. 什么是第八识的「四大功能」（受熏 / 持种 / 根身 / 器）？

**受熏** = 接受前七识现行的熏习，转成种子；**持种** = 执持一切种子（善恶业种、名言种）不失；**根身** = 执持有情的**有根身**（净色五根 + 肉体扶尘根）；**器** = 执持**器世间**（山河大地、无情世界）。这四大功能是第八识的核心作用。

#### 82. 为什么「受熏 + 持种」是种子论的核心？

受熏 = 前七识起用时熏成种子存到第八识；持种 = 第八识执持这些种子不失。这两个功能构成**种子论**：万法都从种子起（种子生现行、现行熏种子），种子存在第八识里。业力如何相续？种子怎么传？—— 全靠第八识受熏持种。这是唯识对「业果相续」的解释。

#### 83. 「根身」跟「器」为什么体现「三界唯心」？

**根身** = 有情的身体（净色五根 + 肉体扶尘根）；**器** = 器世间（山河大地）。这两样都由第八识执持——**有情自身**跟**外部世界**都在第八识里安立。所以「三界唯心」——三界一切都由心（第八识）变现执持。这是唯识对世界的解释。

#### 84. 为什么第八识是「生死轮回的主体」？

生死轮回需要有一个**相续不断的主体**：死时最后离、生时最先来。前七识在死时都散灭，只有第八识**相续不断**地承载种子、执持根身器界。它「去后来先」，是所谓「主公」（主人翁）。若无第八，业力如何相续？生死如何相续？——唯识论主用「持种证、异熟证、生死证」等证明第八识必存在。

#### 85. 为什么第八识「去后来先」？

**去后** = 死亡时，前七识先散灭；**第八识最后离身**（体温最后冷）。**来先** = 受胎时，**第八识最先来结生**（然后其他七识渐次现起）。这就是「作主公」——是生死轮回的主人翁，承载业力从前生到今生。

#### 86. 为什么第八识「相续不断但刹那生灭」既不是断灭也不是常一？

第八识**相续不断**（不断灭：贯穿生死不间断）但**刹那生灭**（不常一：每一刹那都在变化，前后不同）。这是唯识对「常」跟「断」两种极端的回避——若断灭，业果无法相续；若常一，就有「常我」跟无我教相违。第八识「相续不断 + 刹那生灭」正好解决这个矛盾。

### 第三颂：不动地前才舍藏 / 金刚道后异熟空 / 大圆无垢同时发 / 普照十方尘刹中

#### 87. 什么是「不动地」？为什么七地末就要舍藏识？

「不动地」= 十地第八地。「前才舍藏」= 八地之前那一刹那（**七地末进入八地时**）舍「藏识」名。**原因**：第七识**俱生我执现行永伏**，不再执第八为「我」——三藏义中「执藏」义舍。舍藏后第八识改叫「异熟识」。

#### 88. 为什么舍藏识是因为「第七识不再执之为我」？

「藏识」（阿赖耶）得名的关键是**执藏**——被第七识执为「我」。八地起第七识**俱生我执现行永伏**，不再执第八见分为「我」，**执藏义舍**。既然不再被执为我，第八识就不叫「藏识」了，改叫「异熟识」。所以「舍藏」跟第七识的转依是同一件事的两面。

#### 89. 什么是「金刚喻定」？为什么金刚道后异熟识名也空？

**金刚喻定** = 十地末等觉位最后一刹那的**无间道定**（如金刚坚利，能破一切余惑）。「后」= 金刚喻定之后 = 佛果一刹那。「异熟空」= 「异熟识」这个名也舍——因为所有**有漏种子**（含引业种子）**全断尽**，不再有「异熟果」。舍异熟后叫「无垢识」（一切有漏皆断）。

#### 90. 「三个名字」（阿赖耶 / 异熟 / 无垢识）分别在什么阶段用？

- **阿赖耶识**（藏识）= 凡夫至七地末（三藏义全，含被第七执为「我」）
- **异熟识** = 八地至金刚道（舍藏，仍受业力果报，酬引业招异熟果）
- **无垢识** = 佛果（舍异熟，一切有漏皆断，唯余无漏；同时叫「大圆镜智」）

三个名字对应修行的**三个阶段**，标志着转依的进度。

#### 91. 为什么大圆镜智跟成所作智同时起？（都是佛果一刹那）

第八识跟前五识**都要到佛果一刹那才转依**——这是「转依时机分两组」的一组（另一组是六、七识初地就起一分）。为什么？前五识唯自性分别、被动缘境，一定要最深的第八识先转（大圆镜智），前五识才能同时转成所作智。所以佛果一刹那，大圆镜智 + 成所作智 + 无垢识**同时发起**。

#### 92. 大圆镜智跟无垢识是什么关系？（同体异名？）

**大圆镜智** = 佛果位第八识转成的智（能证）；**无垢识** = 佛果位第八识的名（所依）。二者**同体异名**——「智」是能证功德，「识」是所依净分，同时同处一齐现起。所以颂文说「大圆无垢同时发」——不是先后，是同时。

#### 93. 大圆镜智的果用是什么？（自性身 / 自受用 / 持无漏种）

大圆镜智的三大果用：
- **现自性身**（法身，真如显现）
- **自受用报身**（佛自证功德的殊胜报身）
- **持无漏种**（跟凡夫位「持一切种」不同，佛果只持无漏种）
- 加上**映现一切法**（如大圆镜映现万象，遍照十方尘刹）

这是佛果位最根本的功德根据。

#### 94. 「四智分工」是怎样的？（大圆 / 平等 / 妙观察 / 成所作）

四智各主一样：
- **大圆镜智**（第八转）主 **自性身 + 自受用**（佛自证）
- **平等性智**（第七转）主 **他受用身**（度十地菩萨）
- **妙观察智**（第六转）主 **观察诸法自共相 + 说法度生**（度一切众生）
- **成所作智**（前五转）主 **现三类化身**（度凡夫二乘菩萨）

四智分工各不重叠——大圆镜智不说法，平等性智不度凡夫，妙观察智不做自受用，成所作智不诠真。

## 五、综合（95–100）

#### 95. 为什么八识里六识、七识转依早（初地），五识、八识转依晚（佛果）？

**六识、七识**具三种分别 / 计度分别，能力灵活，初地见道就能起一分无漏（分别我执 / 分别法执断）。**前五识**唯自性分别、被动缘境，必须靠第八识先转才能同时转（成所作智）。**第八识**是种子仓库、生死主体，最深最微细，一定要等前七识全部转成无漏（有漏种子全断），第八识才能一齐转成大圆镜智。所以「六七早、五八晚」，五、八佛果一刹那同时转。

#### 96. 为什么第八识转依「最晚也最彻底」？

**最晚**：因为它是种子仓库，一定要等前七识全部转成无漏、有漏种子全断，第八识才能转。**最彻底**：转依分三阶——七地末舍藏（第七不再执之为我）→ 金刚道后舍异熟（所有有漏种子全断）→ 佛果转大圆镜智（同时起无垢识）。三个名字对应三阶段，标志着转依的进度。

#### 97. 修行的「转依」到底是转什么？（八识转四智）

转依 = 转**八识**为**四智**：**前五识** → 成所作智（现三类化身）；**第六识** → 妙观察智（观察诸法 + 说法度生）；**第七识** → 平等性智（现他受用身）；**第八识** → 大圆镜智（现自性身 + 自受用 + 持无漏种）。转依不是「消灭识」，而是「转有漏为无漏」——识的本体不断，只是从染污转成清净。

#### 98. 凡夫跟佛的根本差别在哪里？

差别只在**「转与不转」**：
- **凡夫**：八识全有漏；第七识恒起我执；第八识含一切有漏种子
- **佛**：八识全转成四智；分别、俱生的我执法执种子全断；大圆无垢同发，普照十方尘刹

所以修行的核心就是「转依」——不是「消灭识」，是「转有漏为无漏」，把「造业主 + 我执根 + 种子库」这套凡夫机制，转成「妙观察 + 平等性 + 大圆镜 + 成所作」这套佛的功德机制。

#### 99. 学完《八识规矩颂》4 章，怎么把教理落在日常观照里？

四个观照点：
- 观**前五识**的「性境现量」——如实感知，不加名相概念
- 观**第六识**的「造业动身」——起心动念都是业，动身发语前先观察
- 观**第七识**的「恒审我执」——一切烦恼的根，我慢我爱起时警觉
- 观**第八识**的「一切种子」——善种恶种都在熏习，起善念熏善种

修行不是修「消灭识」，是修「转依」——转有漏为无漏。

#### 100. 为什么说《八识规矩颂》是唯识入门最经典的论？

因为**玄奘大师**（唯识法相宗祖师）用 **3 颂 12 句 x 4 章 = 48 句**，把八识的**体性、所缘、心所相应、烦恼配伍、凡圣转依**全都浓缩讲透——每一识都从「凡夫怎么运作 → 圣者怎么转依」两个层面完整交代。相比《成唯识论》10 卷的义理深广，《八识规矩颂》既完整又浓缩，是进入唯识八识论最经典的入门论。学完这 48 句，唯识的骨架就有了。
