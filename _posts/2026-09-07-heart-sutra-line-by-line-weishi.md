# 写在前面

这里是把《心经》逐句的白话和解释，整理成单独的一篇文章，方便读者查阅。此前已成文[**般若版**](https://mp.weixin.qq.com/s/OtajLZ1CqWWUrbK5yaCmhA)，本篇是**唯识版**——解读全依「唯识无境、三性三无性」的玄奘唯识立场。两版的白话直译**一字不改**，只换解释的立场：同一句经文，站在不同宗派立场读出不同深意，正好逐句对读。后续还会另写**如来藏版**。

# 《心经》白话和解释（唯识版）

* 经名：《般若波罗蜜多心经》，通行本为唐·玄奘大师译
* 内容：一卷 260 字，浓缩六百卷《大般若经》的心要——「心」即心髓、精要之意
* 校准基准：《成唯识论》（护法等造·玄奘译）为核心，兼依《唯识三十颂》（世亲造·玄奘译）、《解深密经》（玄奘译）、《般若波罗蜜多心经幽赞》（窥基撰）
* 立场：唯识 / 法相宗（万法唯识、三性三无性）
* 说明：每句给出经文原文 + 白话直译 + 义理解释 + 术语解释，引及的经论原文另列「参考」；全经解读以「唯识无境、三性三无性」为准。唯识读《心经》的总纲领一句话：**经中的「空」「无」，遣的是遍计所执；依他起的幻有不曾无，圆成实的真实不是无**

## 第一分 · 总纲：照见三性，度一切苦

### 能观之人与所修之行

#### 观自在菩萨

*白话*：观自在菩萨（即观世音菩萨）。

*解释*：「观自在」既是这一位菩萨的名号，也是表法：先有「观」——在唯识，这个观是**无分别智**的观照——才有于诸法、于生死之「自在」。经首标出能观之人，表示下文的境界不是理论推演，而是观行实修的所见；唯识把这条实修之路开为五位（资粮、加行、通达、修习、究竟），后文「以无所得故」以下正是循位而进的果德。

*术语*：
- **观自在** = 梵文 Avalokiteśvara，玄奘译「观自在」，鸠摩罗什译「观世音」——同一位菩萨的两种译名
- **菩萨** = 菩提萨埵（bodhisattva）的简称 = **觉有情**——上求佛道、下化众生者

#### 行深般若波罗蜜多时

*白话*：修行甚深的般若波罗蜜多（智慧到彼岸）之时。

*解释*：标出所修之行与所在之时——观智正现前之时。唯识判「般若」即**无分别智**，开为三种：加行无分别智（观位寻思，带相观空）、根本无分别智（亲证真如，智如冥合）、后得无分别智（证后起用，了达如幻）。「深」是拣别于「浅」：闻思位带名言的知解为浅，与真如相应的无分别智为深。下句「照见五蕴皆空」正是此观现前的所见。

*术语*：
- **般若** = prajñā = 智慧——唯识判为**无分别智**（加行 / 根本 / 后得三种）
- **波罗蜜多** = pāramitā = **到彼岸** / 度——从生死此岸度到涅槃彼岸

#### 照见五蕴皆空

*白话*：观照而亲见：构成身心的五蕴，全都是空。

*解释*：唯识读这一句有确定的落点：「空」的是五蕴上**遍计所执**的实我实法——不是五蕴的显现本身。五蕴是**依他起**——识所变现的幻相，如幻而有、不曾是无；于这幻相上执有离识的实法、常一的实我，这个**所执**才决定非有。所以「照见五蕴皆空」是于五蕴如实了知三性：所执无（相无性）、幻有不无（依他起）、幻有之上二执空所显的真实不无（圆成实）。一个「空」字，三性同时照见。

*术语*：
- **五蕴** = **色**（物质现象）/ **受**（感受）/ **想**（取相、概念）/ **行**（造作、意志等心理活动）/ **识**（了别）——佛对「身心一切现象」的五分归类
- **照见** = 无分别智的**现观**——亲见，不是推理
- **三性三无性**——唯识对「空」的完整判读：

| 三性 | 是什么 | 立三无性 | 有无 |
| --- | --- | --- | --- |
| **遍计所执性** | 于幻相上执有的实我实法 | 相无性（体相都无） | **决定无** |
| **依他起性** | 识所变现的如幻诸法 | 生无性（待缘生，非自然生） | **幻有** |
| **圆成实性** | 二空所显的真如 | 胜义无性（离所执故假说无性） | **真实有** |

*参考*：
- 《唯识三十颂》：「即依此三性，立彼三无性，故佛密意说，一切法无性。」
- 《解深密经》：「一切诸法皆无自性，无生无灭，本来寂静，自性涅槃。」——依三无性密意而说

#### 度一切苦厄

*白话*：（因此）度脱了一切苦难灾厄。

*解释*：度苦不靠别的，正靠「照见皆空」：不了唯识无境，于识所变现的幻相上起遍计执——执我则烦恼障起，执法则所知障起——二障驱业感苦。照见所执本空，二执破则二障息，苦厄自度。这一句是全经总纲——后文一切「无」字都在展开「遣所执」，末尾「能除一切苦」与此首尾呼应。

*术语*：
- **苦厄** = 苦难（内的烦恼逼迫）+ 灾厄（外的灾患障难）
- **二障** = **烦恼障**（执实我而起，障涅槃）/ **所知障**（执实法而起，障菩提）
- **苦的机制**：不了唯识（执心外有境）→ 遍计执实我实法 → 二障 → 造业 → 受苦
- **度苦的机制**：照见所执空 → 二执破 → 二障伏断 → 苦厄自息

## 第二分 · 色空不二：依他与圆成，非异非不异

### 破「色」与「空」为二的误解

#### 舍利子

*白话*：舍利弗啊！

*解释*：呼唤当机听法之人。舍利弗是佛十大弟子中「智慧第一」——般若之义甚深，故对智慧第一的弟子宣说。

*术语*：
- **舍利子** = 舍利弗（Śāriputra）——母亲名「舍利」（鹙鹭鸟），故称「舍利之子」

#### 色不异空，空不异色

*白话*：色不离空，空也不离色。

*解释*：唯识读来，「色」指依他起的色——识所变现的相分，如幻而有；「空」指于色上二执空所显的真如——圆成实性。真如是依他起的**实性**：离开如幻之色，无别处可觅真如（色不异空）；真如也不在幻色之外另成一物（空不异色）。前半句破**执实有**——以为色是离识实有之境；后半句破**执灭色觅空**——以为要撇开幻色，才能另外找到一个真如。

*术语*：
- 「不异」= **不离**——两者不相离、不相外
- **识变** = 色等诸法皆是识所变现的**相分**，非离识外境——「万法唯识」的基本义
- **色**：定义见「照见五蕴皆空」句

*参考*：
- 《唯识三十颂》：「是诸识转变，分别所分别，由此彼皆无，故一切唯识。」

#### 色即是空，空即是色

*白话*：色就是空，空就是色。

*解释*：从「不异」到「即是」是递进：「不异」还容许是两个东西互不相离，「即是」直指不二。唯识以「非异非不异」说这个不二：圆成实与依他起，如「无常性」与无常法——无常性不在无常法之外（非异），无常性又不即是无常法自身（非不异）。「色即是空」：就依他起的幻色，遣其上的所执，当体即显圆成实——不必灭色，也无处灭色。「空即是色」则须简别：**不是**说真如作为本体变现出色——在唯识，变现诸法的是识（种子生现行），真如是无为法，不亲生万法——而是说真如即幻色之实性，如无常性即于诸行上显，说「空即是色」正显实性不离幻相。

*术语*：
- 「即是」vs「不异」：**不异**（不相离）→ **即是**（不二）——遮诠渐深
- **非异非不异** = 圆成实与依他起的关系——以「无常等性」为喻：性不离法、性不即法

*参考*：
- 《唯识三十颂》：「故此与依他，非异非不异，如无常等性，非不见此彼。」

#### 受想行识，亦复如是

*白话*：受、想、行、识，也都是这样。

*解释*：四蕴同理——受想行识是心与心所，同样是识上的依他起幻相：所执无、幻有不无、实性不无。这里有一个唯识特有的要点：「亦复如是」遍该心色，**识自身也在内**——说「唯识」是为遣心外实境，若转过来执「识」为实有，同样是所执，同样在所遣之列。唯识不是「境空而识实」的常见误解。

*术语*：
- **受 / 想 / 行 / 识**：定义见「照见五蕴皆空」句
- 「亦复如是」= 同样如此——省略展开的十六句

*参考*：
- 《成唯识论》：「为遣妄执心心所外实有境故，说唯有识；若执唯识真实有者，如执外境，亦是法执。」

## 第三分 · 诸法空相：圆成实离一切相

### 真如离言离相

#### 舍利子，是诸法空相

*白话*：舍利弗啊！这一切法的空性之相……

*解释*：再唤舍利弗，引出更深一层：「空相」即二空（我空、法空）所显的**真如**——圆成实性，诸法的真实性。真如离名言、离分别：凡可用名言安立、可被分别抓取之相，皆是遍计门中事；真如以「无相」为相。下面三句用六个「不」，遮遣一切安在真如上的相对之相。

*术语*：
- **空相** = **二空所显真如** = 圆成实性——诸法的真实性
- **二空** = 我空（补特伽罗无我）+ 法空（法无我）

*参考*：
- 《成唯识论》（释「真如」）：「真谓真实，显非虚妄；如谓如常，表无变易。」
- 《唯识三十颂》：「此诸法胜义，亦即是真如，常如其性故，即唯识实性。」

#### 不生不灭

*白话*：不曾（真实地）生起，也不曾（真实地）灭去。

*解释*：生灭是依他起上的事——有为法待缘而生、刹那而灭；真如是**无为法**，不待因缘造作，「常如其性」，故无生可生、无灭可灭。说「生灭」是就识变的幻事，说「不生不灭」是就幻事的实性——两句不相违，各有所指。

*术语*：
- **有为法** = 待缘造作、有生灭者（依他起摄）；**无为法** = 非造作、无生灭者（真如是其体）

*参考*：
- 《解深密经》：「一切诸法皆无自性，无生无灭，本来寂静，自性涅槃。」

#### 不垢不净

*白话*：没有（真实的）染污，也没有（真实的）清净。

*解释*：真如在缠不为客尘所染——若烦恼真能染污真如，则永无解脱之理（不垢）；出缠也不是新添了一个净——净非新得，只是离障而显（不净）。染净的升沉，是依他起上有漏无漏种子、现行的事；真如理体，其性不改。这不是说不用断染修净——正因为染只是客、净本非新，转染成净才有可能、有着落。

*术语*：
- **客尘** = 烦恼杂染——「客」表非真如本有，「尘」表能蔽
- **有漏 / 无漏** = 随顺杂染的种子现行 / 随顺清净的种子现行

*参考*：
- 《成唯识论》（释本来自性清净涅槃）：「谓一切法相真如理，虽有客染而本性净。」

#### 不增不减

*白话*：不曾增加，也不曾减少。

*解释*：约凡圣位说：成圣转依，似有所「得」；沉沦生死，似有所「失」。但转依的舍与得，都在依他起上——舍的是二障种子，得的是清净种子现行；真如理体，在圣不增一分、在凡不减一分，转依只是「显」得，不是新造。三句合观：不生不灭约**有为无为**之判、不垢不净约**染净**、不增不减约**凡圣**——三对六字，遮尽安在真如上的一切相对之相；真如既离一切相，其中自然「无」一切所执之法，由此引出下一分。

*术语*：
- **三对六字**：生灭（约有为无为）/ 垢净（约染净）/ 增减（约凡圣）
- **转依**（预告，详见第五分）：转舍、转得皆在依他起上，真如无增减

## 第四分 · 空中无法：「无」者，遣遍计所执

「空中无 X」的「无」，唯识读来有确定的落点：**无的是遍计所执**——于蕴处界乃至智得上所执的离识实法，决定非有；依他起的幻相不曾无，圆成实的实性不是无。窥基大师《心经幽赞》正是这样判定全经「无」字的分际：显所执无，不遣依他、圆成。若把「无」读成一切都无，连幻有实性也拨掉，唯识名之为「恶取空」。这一分依次列举蕴处界三科、十二因缘、四谛、智与得，遣其上的所执。

### 蕴 · 处 · 界上的所执无

#### 是故空中无色，无受想行识

*白话*：所以空性之中没有色，也没有受、想、行、识。

*解释*：承上：真如性中无一切所执之相，故「空中无色」。三性分判：识变的五蕴幻相宛然（依他起，不无）；所执的离识实蕴决定无（遍计执，此句所「无」）；真如非蕴相（圆成实，不无）。「无」字遣所执，不拨幻有——若连识变的幻蕴也说无，便堕恶取空，染净因果都无从安立。这句总明五蕴上的所执无，即三科的第一科。

*术语*：
- **恶取空** = 把「空」错取为一切皆无，连依他起、圆成实也拨无——唯识判为最难救治的错解
- **三科** = 蕴 / 处 / 界——佛对「一切法」的三种开合归类

*参考*：
- 《成唯识论》：「拨无二者，是恶取空，诸佛说为不可治者。」（「二」指依他起性与圆成实性）

#### 无眼耳鼻舌身意，无色声香味触法

*白话*：没有眼、耳、鼻、舌、身、意，也没有色、声、香、味、触、法。

*解释*：十二处（三科的第二科）上的所执亦无：六根是识所依的净色与意，六尘是识所现的相分——根、境俱不离识。所执的「离识实根、心外实境」决定非有；根尘的幻相与功能不无——见色闻声宛然，只是无一法在识外。

*术语*：
- **六根** = 眼 / 耳 / 鼻 / 舌 / 身 / 意——能取的六种感官功能
- **六尘** = 色 / 声 / 香 / 味 / 触 / 法——所取的六种境界（「法尘」= 意根所对的观念、影像）
- 六根 + 六尘 = **十二处**——「处」= 生长门，识由此生

#### 无眼界，乃至无意识界

*白话*：没有眼界，乃至没有意识界。

*解释*：十八界（三科的第三科）上的所执亦无。至此蕴、处、界三科说尽——三科是佛对一切法的三种开合，唯识自宗则把一切法开为五位百法，两套分类互摄。为什么立了三科，又说三科皆无？立，是世俗谛中对治「执我」（分析身心为蕴处界，见其中无我）；说「无」，是胜义谛中对治「执法」（不复执蕴处界为离识实法）。

*术语*：
- **十八界** = 六根界 + 六尘界 + 六识界（眼识乃至意识）
- **五位百法** = 心法 8 / 心所法 51 / 色法 11 / 不相应行法 24 / 无为法 6——唯识对一切法的开合
- **二谛** = **世俗谛**（就依他幻有安立的道理）/ **胜义谛**（就真如实性说的道理）
- 「乃至」= **超略之词**——只举第一（眼界）与最后（意识界），中间十六界省略

### 十二因缘上的所执无

#### 无无明，亦无无明尽；乃至无老死，亦无老死尽

*白话*：没有无明，也没有无明的灭尽；乃至没有老死，也没有老死的灭尽。

*解释*：十二因缘在唯识是识上**种现相续的分位假立**——流转门是杂染种子生现行、现行熏种子的相续；还灭门是有漏种渐伏渐断的次第。此句遣其上的所执：执流转为离识实有的锁链、执还灭为实有一物可灭可尽，二执俱非。而种现因果的幻有不无——正因为流转唯是识变、并非实法，转染成净才有可能；若无明是离识实有，则永不可断。

*术语*：
- **十二因缘** = 无明 → 行 → 识 → 名色 → 六入 → 触 → 受 → 爱 → 取 → 有 → 生 → 老死——「乃至」再次超略中间十支
- **种现相续**：**种子**（阿赖耶识中生果功能）生**现行**，现行复熏成种——唯识的因果模型
- **流转门**（顺观）：杂染种现相续；**还灭门**（逆观）：无明**尽**（灭）则行尽，乃至老死尽；「尽」= 灭尽

### 四谛上的所执无

#### 无苦集灭道

*白话*：没有苦、集、灭、道。

*解释*：四谛上的所执亦无：苦、集是杂染的依他起（惑业苦的种现因果），灭、道是清净的依他起与所显的圆成实。此句不是否定四谛在世俗谛中的观行价值，而是遣「实有苦可厌、实有集可断、实有灭可证、实有道可修」的执相。染净因果宛然而立，四谛观行照修不误——只是无一谛在识外、无一相可执实。

*术语*：
- **四谛** = **苦**（果：生死是苦）/ **集**（因：苦由烦恼与业集起）/ **灭**（果：苦可灭，即涅槃）/ **道**（因：灭苦之道，即八正道）——世间因果一对 + 出世间因果一对
- **唯识判四谛**：苦、集 = 杂染因果（有漏种现）；灭、道 = 清净因果（无漏种现与真如）

### 智与得上的所执无

#### 无智亦无得

*白话*：没有智，也没有得。

*解释*：最深的一层，也正是唯识观行的核心一步：无分别智亲证真如时，智与真如**平等平等**——不现能取之相，不现所取之相；若还见「我有能观之智、我有所证之得」，便仍是二取，仍未入真唯识性。《唯识三十颂》的通达位颂说的正是这个境界：「智都无所得」之时，才是「住唯识」之时。与前「若执唯识真实有者亦是法执」合看：遣执遣到能观之智自身，唯识与般若在这里同归一处。

*术语*：
- **智** = 能观的**无分别智**；**得** = 所证的**菩提、涅槃果**
- **二取** = **能取**（执能缘之心为实）+ **所取**（执所缘之境为实）——二取相泯，方证真如
- **通达位** = 五位之第三——无分别智初起、初证真如之位（即见道）

*参考*：
- 《唯识三十颂》：「若时于所缘，智都无所得，尔时住唯识，离二取相故。」

## 第五分 · 菩萨果德：无所得入通达，转依至究竟

### 依般若而心无罣碍

#### 以无所得故，菩提萨埵，依般若波罗蜜多故，心无罣碍

*白话*：因为无所得，菩萨依止般若波罗蜜多，心中没有牵挂障碍。

*解释*：这是全经的枢纽句：上承「无智亦无得」——「无所得」正是通达位智证真如的相貌；下启菩萨、诸佛的果德——由通达位入修习位，数数熏修无分别智，渐断二障种子。「心无罣碍」即二障渐伏渐断之相：心取一法为实，即被一法所系；二取既泯，无一法可罣心。

*术语*：
- **菩提萨埵** = 菩萨的全称
- **罣碍**：「罣」= 牵挂（如网罣物）；「碍」= 障碍——唯识义即**二障系缚**
- **五位** = **资粮位**（积福智）→ **加行位**（伏二取）→ **通达位**（初证真如）→ **修习位**（数断二障）→ **究竟位**（转依成满）——「以无所得故」以下，正循此位次而进

#### 无罣碍故，无有恐怖

*白话*：因为心无罣碍，所以没有恐怖。

*解释*：一切怖畏都从执「有我可失、有法可失」而来——我执（烦恼障）是怖畏的根。修习位中我执渐伏渐断，无可失者则无所怖。

*术语*：
- **五怖畏**（地前所有）：不活畏 / 恶名畏 / 死畏 / 恶道畏 / 大众威德畏——我执伏断，五畏皆离
- **果德次第**：无所得（通达）→ 无罣碍（修习断障）→ 无恐怖 → 离颠倒 → 究竟涅槃（究竟位）——层层递进

#### 远离颠倒梦想，究竟涅槃

*白话*：远离颠倒和梦想，达到究竟的涅槃。

*解释*：颠倒是遍计执上的四种倒见；「梦想」二字在唯识读来尤其亲切——**梦正是唯识无境的第一喻**：梦中境界识所变现，了无外实，梦者却执为真；凡夫于识变诸法起实执，正如梦中人。远离颠倒梦想，即从执梦为实中醒来。「究竟涅槃」在唯识指四种涅槃中的**无住处涅槃**：断尽二障、真如全显，由般若故不住生死，由大悲故不住涅槃，尽未来际利乐有情。

*术语*：
- **四颠倒** = 于**无常**执常 / 于**苦**执乐 / 于**无我**执我 / 于**不净**执净
- **梦喻** = 唯识以梦显「识变无境」——境虽无实，梦相宛然
- **四种涅槃** = 本来自性清净涅槃 / 有余依涅槃 / 无余依涅槃 / **无住处涅槃**（唯佛具四）

*参考*：
- 《成唯识论》：「无住处涅槃，谓即真如出所知障，大悲般若常所辅翼，由斯不住生死涅槃，利乐有情，穷未来际。」

### 诸佛同依般若成佛

#### 三世诸佛，依般若波罗蜜多故，得阿耨多罗三藐三菩提

*白话*：过去、现在、未来的一切佛，都依般若波罗蜜多，证得无上正等正觉。

*解释*：举三世，表无一佛例外——成佛必由无分别智。唯识说这个「得」为**转依**：转舍依他起上的二障种子，转得涅槃与菩提二果——断烦恼障故证大涅槃，断所知障故得大菩提；究竟位中八识转成四智（大圆镜智、平等性智、妙观察智、成所作智，转依详说见《八识规矩颂》逐句解释一文）。「得」而无所得：转依是离障显得与修满而成，不是从外新得一物——与上文「无智亦无得」呼应，两不相违。

*术语*：
- **三世** = 过去 / 现在 / 未来
- **阿耨多罗三藐三菩提** = anuttarā samyak-saṃbodhi = **无上正等正觉**——「无上」（更无有上）+「正等」（遍知平等）+「正觉」（真实觉悟）
- **转依** = 转舍二障、转得二果（涅槃 + 菩提）——唯识对「成佛」的完整表述
- **四智** = 大圆镜智（第八识转）/ 平等性智（第七识转）/ 妙观察智（第六识转）/ 成所作智（前五识转）

*参考*：
- 《成唯识论》：「由断续生烦恼障故，证真解脱；由断碍解所知障故，得大菩提。」

## 第六分 · 总赞与咒：显密双说

### 四叹般若

#### 故知般若波罗蜜多，是大神咒，是大明咒，是无上咒，是无等等咒

*白话*：所以应当知道：般若波罗蜜多是大神咒，是大明咒，是无上咒，是无等等咒。

*解释*：以「咒」赞叹般若：咒即总持，以少字总摄无量义——正如本经以 260 字总持六百卷之要。般若的「神力」不从外来：无分别智现前，二障应念伏断，即是破魔；智光照处，遍计的暗执不起，即是光明。

*术语*：
- **咒** = 总持（陀罗尼，dhāraṇī）——以少字**总摄无量义**而不失
- **四叹**：**大神咒**（神力大——能伏断二障魔怨）/ **大明咒**（光明大——能照破无明暗执）/ **无上咒**（更无一法在其上）/ **无等等咒**（无有能与之等者；一说：与「无等」之佛果相等）

#### 能除一切苦，真实不虚

*白话*：（般若）能除灭一切苦，真实而不虚妄。

*解释*：呼应总纲「度一切苦厄」——开头标宗，这里结成，全经首尾圆合。度苦的路在唯识说得分明：照见所执空，二障断，苦即除——般若不是玄谈，度苦是转依路上可以验证的真实受用。

*术语*：
- **真实不虚** = 佛语诚谛——劝信之辞

### 说咒

#### 故说般若波罗蜜多咒，即说咒曰：揭谛揭谛，波罗揭谛，波罗僧揭谛，菩提萨婆诃

*白话*：所以宣说般若波罗蜜多咒，咒是这样说的：揭谛揭谛，波罗揭谛，波罗僧揭谛，菩提萨婆诃。

*解释*：前文以义理**显说**般若（三性三无性、五位转依），末后以咒语**密说**般若——显说令人依解起行，密说令人离解直行；一显一密，同归「度到彼岸」。咒依例音译不翻，属玄奘「五种不翻」中的**秘密不翻**：重在音声总持、一心受持，不重字面训解。

*术语*：
- 梵音：**gate gate pāragate pārasaṃgate bodhi svāhā**
- 通行释义：**揭谛**（去 / 度）/ **波罗揭谛**（到彼岸去）/ **波罗僧揭谛**（大家一同到彼岸去）/ **菩提**（觉悟）/ **萨婆诃**（速疾成就、圆满吉祥）——大意是：去吧！去吧！到彼岸去吧！大家一同到彼岸去吧！觉悟，速疾成就！

## 附三：「空」的正解与误解对照（唯识）

| | 误解的「空」 | 唯识的「空」 |
| --- | --- | --- |
| 定义 | 什么都没有、不存在 | **遍计所执无**——所执的离识实我实法决定非有 |
| 与现象的关系 | 否定现象（恶取空） | **依他起不无**——识变幻相宛然，见色闻声不误 |
| 与真实的关系 | 空掉一切，无有真实 | **圆成实不无**——二空所显真如真实有 |
| 与修行的关系 | 既然皆空，无可修证 | **转依可成**——正因所执空、幻有可转，染净因果宛然 |
| 与「识」的关系 | 境空而识实有 | **执唯识亦是法执**——「如执外境」，识亦在所遣之列 |
| 空本身 | 执「空」为一个实有的东西 | **智都无所得**——遣执遣到能观之智，二取俱泯 |

**一句话总结**：《心经》的「空」，唯识读来就是「**三性三无性**」——所执决定无（相无性），幻有不曾无（生无性），真实不是无（胜义无性）。「无」字遣执不遣法：遣尽遍计、二取俱泯，于依他起上转舍二障、转得菩提涅槃——这就是唯识版的《心经》。

—— 整理：愚千一
