这里是把《心经》逐句的白话和解释，整理成单独的一篇文章，方便读者查阅。此前已成文[**般若版**](https://mp.weixin.qq.com/s/OtajLZ1CqWWUrbK5yaCmhA)与[**唯识版**](https://mp.weixin.qq.com/s/xM9I7A_GPIU6RmE7blTKrw)，本篇是**如来藏版**——解读全依「自性清净心、相妄性真」的如来藏立场。三版的白话直译**一字不改**，只换解释的立场：同一句经文，站在不同宗派立场读出不同深意，正好逐句对读。至此，三版圆满。

# 《心经》白话和解释（如来藏版）

* 经名：《般若波罗蜜多心经》，通行本为唐·玄奘大师译
* 内容：一卷 260 字，浓缩六百卷《大般若经》的心要——「心」即心髓、精要之意
* 校准基准：《大乘起信论》（马鸣菩萨造·真谛译）为核心，兼依《楞严经》（般剌蜜帝译）、《胜鬘经》（求那跋陀罗译）、《圆觉经》（佛陀多罗译）
* 立场：如来藏 / 真常唯心（一心二门、自性清净心）
* 说明：每句给出经文原文 + 白话直译 + 义理解释 + 术语解释，引及的经论原文另列「参考」；全经解读以「一心二门、相妄性真」为准。如来藏读《心经》的总纲领一句话：**经中的「空」「无」，空的是真心上的客尘妄染与妄执之相；真心本具的性德不空——相妄性真，全相即性**

## 第一分 · 总纲：照见相妄性真，度一切苦

### 能观之人与所修之行

#### 观自在菩萨

*白话*：观自在菩萨（即观世音菩萨）。

*解释*：「观自在」既是这一位菩萨的名号，也是表法：先有「观」——在如来藏教，这个观是**回光返照**：不向外攀缘境相，而是照了能观所观同出一心——才有于诸法、于生死之「自在」。经首标出能观之人，表示下文的境界不是理论推演，而是观照实修的所见；全经在如来藏读来，是一场「认妄识真」的返照。

*术语*：
- **观自在** = 梵文 Avalokiteśvara，玄奘译「观自在」，鸠摩罗什译「观世音」——同一位菩萨的两种译名
- **菩萨** = 菩提萨埵（bodhisattva）的简称 = **觉有情**——上求佛道、下化众生者

#### 行深般若波罗蜜多时

*白话*：修行甚深的般若波罗蜜多（智慧到彼岸）之时。

*解释*：标出所修之行与所在之时——观照正现前之时。如来藏教判「般若」为**本觉智光**：这不是从外新修得的一种能力，而是真心本来具足的照用；所谓修行，只是拂拭客尘，让本有的光明透出（始觉是本觉之光初透）。「深」是拣别于「浅」：向外分别取相的知解为浅，回光返照、与本觉相应的观照为深。下句「照见五蕴皆空」正是此观现前的所见。

*术语*：
- **般若** = prajñā = 智慧——如来藏教判为**本觉之智**：真心本具的照用，非外铄
- **波罗蜜多** = pāramitā = **到彼岸** / 度——从生死此岸度到涅槃彼岸

#### 照见五蕴皆空

*白话*：观照而亲见：构成身心的五蕴，全都是空。

*解释*：如来藏读此句的落点是**相妄性真**。五蕴是真心随缘所现的妄相——如水起波、如空现花。说「皆空」有两层：一层是**妄相无体**——波外无水、相外无性，五蕴之相求其实体了不可得；一层是**当体即真**——「空」字所指正是五蕴的本性，即自性清净的真心。空的是妄染妄执（空如来藏义），空不掉的是心体本具的恒沙性德（不空如来藏义）——一个「空」字，二义具足。

*术语*：
- **五蕴** = **色**（物质现象）/ **受**（感受）/ **想**（取相、概念）/ **行**（造作、意志等心理活动）/ **识**（了别）——佛对「身心一切现象」的五分归类
- **照见** = 回光返照的**现观**——亲见，不是推理
- **如来藏** = 一切众生本具的**自性清净心**——在缠（为客尘所覆）名如来藏，出缠名法身
- **空如来藏 / 不空如来藏**：空义——离一切烦恼客尘；不空义——本具过恒沙数不思议性德

*参考*：
- 《胜鬘经》：「空如来藏，若离、若脱、若异一切烦恼藏；不空如来藏，过于恒沙不离、不脱、不异、不思议佛法。」

#### 度一切苦厄

*白话*：（因此）度脱了一切苦难灾厄。

*解释*：苦的根源，如来藏教说得最切身：**迷真逐妄**——不识本心，认妄相为实我实境，如演若达多迷头认影、无故狂走；由迷起惑，由惑造业，由业感苦。照见相妄性真，狂心当下歇息——歇处即是菩提，苦厄自度。这一句是全经总纲——后文一切「无」字都在展开「照妄识真」，末尾「能除一切苦」与此首尾呼应。

*术语*：
- **苦厄** = 苦难（内的烦恼逼迫）+ 灾厄（外的灾患障难）
- **苦的机制**：迷真心（一念不觉）→ 认妄相为实 → 起惑造业 → 受苦
- **度苦的机制**：回光返照 → 识得相妄性真 → 狂心歇息 → 苦厄自息
- **演若达多喻**（《楞严经》）：城中狂人晨朝揽镜，爱镜中头，嗔责己头不见面目，无故狂走——头本未失，狂歇即是

*参考*：
- 《楞严经》：「狂性自歇，歇即菩提。」

## 第二分 · 色空不二：全相即性，全性起相

### 破「色」与「空」为二的误解

#### 舍利子

*白话*：舍利弗啊！

*解释*：呼唤当机听法之人。舍利弗是佛十大弟子中「智慧第一」——般若之义甚深，故对智慧第一的弟子宣说。

*术语*：
- **舍利子** = 舍利弗（Śāriputra）——母亲名「舍利」（鹙鹭鸟），故称「舍利之子」

#### 色不异空，空不异色

*白话*：色不离空，空也不离色。

*解释*：如来藏读来，色是真心随缘现起之相（波），空是色的本性即真心（水）。波不在水外——色不异空；水不在波外——空不异色：性与相从来不曾分家。前半句破**执相实有**——认波为离水独立之物；后半句破**离相觅性**——以为要拨开波浪、离开幻色，才能另外找到一个真心。离波觅水，无有是处。

*术语*：
- 「不异」= **不离**——两者不相离、不相外
- **随缘不变、不变随缘** = 如来藏与万相关系的总纲——随缘现相而体不变动，体虽不变而能随缘现起
- **色**：定义见「照见五蕴皆空」句

#### 色即是空，空即是色

*白话*：色就是空，空就是色。

*解释*：从「不异」到「即是」是递进：「不异」还容许是两个东西互不相离，「即是」直指不二。如来藏立场读这两句，正是**全相即性、全性起相**：「色即是空」——波全体是水，相全体是性，不必息波觅水、灭色明空；「空即是色」——水全体成波，**性能起相**：真心随缘，举体现为根身器界。在般若版、唯识版中须简别的「性起」，在如来藏立场正是宗眼所在。但仍须简别：真心随缘现相，不是说心是一个立于相外的「造物者」在制造万相——性相不二，起相之时体不动摇，如水成波而「水非动性」；所现之相亦如梦如影，妄相原无实体，不是实有生起。

*术语*：
- 「即是」vs「不异」：**不异**（不相离）→ **即是**（不二）——遮诠渐深
- **全相即性 / 全性起相**：相之全体即是性（即相见性，不必坏相）/ 性之全体起为相（性起，不是性外别有相生）

*参考*：
- 《大乘起信论》：「如大海水，因风波动，水相风相不相舍离，而水非动性；若风止灭，动相则灭，湿性不坏故。」

#### 受想行识，亦复如是

*白话*：受、想、行、识，也都是这样。

*解释*：四蕴同理——受想行识是真心随缘所现的心念之波，同样相妄性真、全相即性。这里有一个如来藏教特别叮咛的要点：不可读成「身境是妄，而我这个能思能想的心是真」——五蕴中的识蕴、想蕴同样是妄相；**攀缘思量的识心不是真心**，它只是真心上的波纹。把缘影妄心认作本来真心，是修行路上的第一错认（《楞严经》七处征心，征的正是这个）。

*术语*：
- **受 / 想 / 行 / 识**：定义见「照见五蕴皆空」句
- 「亦复如是」= 同样如此——省略展开的十六句
- **真心 vs 妄心**：本觉真心（体，不生不灭）/ 攀缘识心（相，念念生灭）——「认贼为子」之诫

## 第三分 · 诸法空相：心真如门

### 真心离相离言

#### 舍利子，是诸法空相

*白话*：舍利弗啊！这一切法的空性之相……

*解释*：再唤舍利弗，引出更深一层：「空相」即是**心真如**——一法界大总相法门体：一切法共同的真实体，就是这一味真心。真如离言离相：凡可以名言安立、可被心缘取着的，都已落在生灭门的相中；真心之体，言语道断、心行处灭。下面三句用六个「不」，遮尽妄念安在真心上的一切相对之相。

*术语*：
- **空相** = **心真如** = 真心之体——诸法的真实性
- **一心二门**（《起信论》全书纲骨）：**心真如门**（不生不灭之体）/ **心生灭门**（随缘起灭之相）——依一心开二门，二门不相离

*参考*：
- 《大乘起信论》：「心真如者，即是一法界大总相法门体。所谓心性不生不灭；一切诸法唯依妄念而有差别，若离妄念，则无一切境界之相。」

#### 不生不灭

*白话*：不曾（真实地）生起，也不曾（真实地）灭去。

*解释*：生灭是生灭门中、依妄念而现之相；真心之体本不生灭。要紧处在于：不是把生灭止息之后另外得到一个不生灭——而是生灭当下，其体本自不生灭，如波起波落，水体不曾随波生灭。说「生灭」约相，说「不生不灭」约性——二门不相离，两说不相违。

*术语*：
- **体 / 相**之判：真如门约体说（不生灭）/ 生灭门约相说（有起灭）——同一心，两重看

*参考*：
- 《大乘起信论》：「一切诸法从本已来，离言说相，离名字相，离心缘相，毕竟平等，无有变异，不可破坏，唯是一心，故名真如。」

#### 不垢不净

*白话*：没有（真实的）染污，也没有（真实的）清净。

*解释*：真心**自性清净**：客尘烦恼覆之而不能染其体（不垢）——若心体真能被染坏，众生便永无成佛之理；离染出缠也不是新添一个净（不净）——净是本具，不从外得，出缠只是显出本来。「自性清净心而有染污」是如来藏教承认为最难思议的一环：染只是相上客尘，不碍性体本净——也正因如此，转染还净才有真实的依据。

*术语*：
- **自性清净心** = 心体本净，染不能污——如来藏的核心表述
- **客尘** = 烦恼杂染——「客」表非本有，「尘」表能蔽而不能染体
- **在缠 / 出缠**：定义见「照见五蕴皆空」句（如来藏 / 法身）

*参考*：
- 《胜鬘经》：「自性清净心而有染污，难可了知。」

#### 不增不减

*白话*：不曾增加，也不曾减少。

*解释*：在圣不增、在凡不减——这层义理在如来藏教是有专经正面宣说的（《不增不减经》即以此立名）：众生界即是法身，迷时性德无损一分，悟时性体无添一分。所以修行是**显本**，不是造新：如磨镜，垢尽明现，明不是磨出来的新东西。三句合观：不生不灭约**体相**之判、不垢不净约**染净**、不增不减约**凡圣**——三对六字，遮尽妄念安立的一切相对之相；真心既离一切相，其中自然「无」一切妄法，由此引出下一分。

*术语*：
- **三对六字**：生灭（约体相）/ 垢净（约染净）/ 增减（约凡圣）
- **显本** = 修德有功、性德方显——修不是造作真如，是除尘显镜

## 第四分 · 空中无法：妄相本空，本如来藏妙真如性

「空中无 X」的「无」，如来藏读来是**妄相于真心中本无所有**——如空花之于虚空、梦境之于醒眼：迷时似有，照时本无。而每一句「无」同时还有一层表诠之义：蕴处界等既是真心随缘所现，说「无」正显其**当体即真**——《楞严经》对五阴、六入、十二处、十八界逐一印定「本如来藏妙真如性」，与本分逐科说「无」，一遮一表，正好对读。这一分依次列举蕴处界三科、十二因缘、四谛、智与得。

### 蕴 · 处 · 界：妄相本空

#### 是故空中无色，无受想行识

*白话*：所以空性之中没有色，也没有受、想、行、识。

*解释*：真心之中（真如门中）无五蕴妄相——如镜中像不在镜体上留痕、空中花不在虚空中实有。「无」不是把现前五蕴消灭掉，而是照见其从来无实：幻相「当处出生，随处灭尽」，从未在真心上真正安立过；而幻相之性即是妙觉明体——所以「无色」之处，正是「全体是真」之处。遮妄与显真，是同一句话的两面。

*术语*：
- **三科** = 蕴 / 处 / 界——佛对「一切法」的三种开合归类
- **空花喻 / 镜像喻**：如来藏教常用二喻——目病见空花，花相宛然而虚空不曾生花；镜现万像而镜体不染

*参考*：
- 《楞严经》：「一切浮尘诸幻化相，当处出生，随处灭尽，幻妄称相，其性真为妙觉明体。」

#### 无眼耳鼻舌身意，无色声香味触法

*白话*：没有眼、耳、鼻、舌、身、意，也没有色、声、香、味、触、法。

*解释*：十二处的妄相亦本空：能取的六根、所取的六尘，相对而立，皆是真心中所现之影——离心无根可得，离心无尘可对。《楞严经》七处征心、十番显见之后，正是逐一会通六入、十二处「本如来藏妙真如性」：遮其妄相，显其真性，与此句同一血脉。

*术语*：
- **六根** = 眼 / 耳 / 鼻 / 舌 / 身 / 意——能取的六种感官功能
- **六尘** = 色 / 声 / 香 / 味 / 触 / 法——所取的六种境界（「法尘」= 意根所对的观念、影像）
- 六根 + 六尘 = **十二处**——「处」= 生长门，识由此生

#### 无眼界，乃至无意识界

*白话*：没有眼界，乃至没有意识界。

*解释*：十八界亦然。至此蕴、处、界三科说尽——《楞严经》以同一句话逐科印定：「本如来藏妙真如性」。为什么立了三科，又说三科皆无？立，是世俗中对治「执我」（分析身心为蕴处界，见其中无我）；说「无」，是对治「执法」（不复执蕴处界为实法）；而如来藏教还多说一层：遮妄之后**指真**——三科非但相空，且全体即是藏性，无一法遗留在真心之外。

*术语*：
- **十八界** = 六根界 + 六尘界 + 六识界（眼识乃至意识）
- 「乃至」= **超略之词**——只举第一（眼界）与最后（意识界），中间十六界省略

*参考*：
- 《楞严经》：「云何五阴，本如来藏妙真如性？」（六入、十二处、十八界，经中一一同此印定）

### 十二因缘：迷悟之相本空

#### 无无明，亦无无明尽；乃至无老死，亦无老死尽

*白话*：没有无明，也没有无明的灭尽；乃至没有老死，也没有老死的灭尽。

*解释*：十二因缘在如来藏教是**一念不觉**的展开——「依本觉故而有不觉」：无明不是一件实物，只是真心的一念迷；迷本无根，如演若达多之狂，狂性无体——所以「无无明」；狂歇之时也不是除掉了一个实法——所以「亦无无明尽」。流转门是迷相，还灭门是悟相，迷悟之相皆依真而起、皆无自体，而真心不属迷悟。正因为无明无体，无明才能尽；若无明实有，则永不可断。

*术语*：
- **十二因缘** = 无明 → 行 → 识 → 名色 → 六入 → 触 → 受 → 爱 → 取 → 有 → 生 → 老死——「乃至」再次超略中间十支
- **本觉 / 不觉 / 始觉**：依**本觉**而有**不觉**（一念妄动，展开为流转）；依不觉故说**始觉**（返照还源，即是还灭）
- **流转门**（顺观）/ **还灭门**（逆观）：迷相的展开 / 悟相的次第；「尽」= 灭尽

*参考*：
- 《大乘起信论》：「始觉义者：依本觉故而有不觉，依不觉故说有始觉。」

### 四谛：染净之相本空

#### 无苦集灭道

*白话*：没有苦、集、灭、道。

*解释*：四谛是就迷悟两重因果安立的：苦、集是迷真逐妄的**染缘起**，灭、道是返妄归真的**净缘起**——都是生灭门中事。真如门中，染净因果之相俱不可得。这不是废弃四谛的观行，而是行四谛时不执四谛为实法——知苦本空（妄相无体）、断集即歇（狂心非实）、证灭非新（涅槃本具）、修道是显（修德显本）：四谛行门，在如来藏教中全部落在「歇」与「显」两个字上。

*术语*：
- **四谛** = **苦**（果：生死是苦）/ **集**（因：苦由烦恼与业集起）/ **灭**（果：苦可灭，即涅槃）/ **道**（因：灭苦之道，即八正道）——世间因果一对 + 出世间因果一对
- **如来藏判四谛**：苦集 = 染缘起（不觉之相）；灭道 = 净缘起（始觉之相）

### 智与得：始觉不异本觉

#### 无智亦无得

*白话*：没有智，也没有得。

*解释*：最深的一层：能观之智，即是本觉自己的光——智外无如、如外无智；悟时只是始觉合于本觉，「实无有始觉之异」。觉性既是本有，何曾新得一物（无得）；能所既泯于一心，何存能观之智（无智）。若还存着「我有智慧能证、有真心可得」，便仍是拿妄心去捉真心——头上安头，骑牛觅牛。三版至此同归一处：遣执遣到能观之智自身，方是彻底。

*术语*：
- **智** = 能观的**本觉之智**；**得** = 所证的**菩提、涅槃果**
- **始觉合本** = 始觉圆满即同本觉——悟无别悟，只是复本；证无新证，只是亲归

*参考*：
- 《大乘起信论》：「实无有始觉之异……本来平等，同一觉故。」

## 第五分 · 菩萨果德：返妄归真，复本心源

### 依般若而心无罣碍

#### 以无所得故，菩提萨埵，依般若波罗蜜多故，心无罣碍

*白话*：因为无所得，菩萨依止般若波罗蜜多，心中没有牵挂障碍。

*解释*：这是全经的枢纽句：上承「无智亦无得」——菩提涅槃本自具足，无一法从外新得；下启菩萨、诸佛的果德。正因本有故无所求，菩萨依般若（本觉之照）而行，行处无求——无求则无系，心自无罣碍。罣碍从「向外有所取」生：心取一相则被一相罣，逐一物则被一物碍；识得万相唯是一心，则无一物当情。

*术语*：
- **菩提萨埵** = 菩萨的全称
- **罣碍**：「罣」= 牵挂（如网罣物）；「碍」= 障碍——取相则罣，逐物则碍

#### 无罣碍故，无有恐怖

*白话*：因为心无罣碍，所以没有恐怖。

*解释*：一切怖畏都从**认妄为真**来：认幻身为我，则怖其坏灭；认幻境为实，则怖其失去。识得相妄性真，怖畏失去依据——性无可坏（本不生灭），相无可失（本来即幻）：无可失者，无所怖。

*术语*：
- **五怖畏**（地前所有）：不活畏 / 恶名畏 / 死畏 / 恶道畏 / 大众威德畏——识真则五畏皆离
- **果德次第**：无所得 → 无罣碍 → 无恐怖 → 离颠倒 → 究竟涅槃——层层递进

#### 远离颠倒梦想，究竟涅槃

*白话*：远离颠倒和梦想，达到究竟的涅槃。

*解释*：颠倒是认妄为真、迷头认影的倒见；「梦想」在如来藏教读来最为切身——众生轮回，正是一场**长夜大梦**：梦中事非实有，而梦中人历然受苦。如来藏教的醒梦之道也最直截：「知幻即离，不作方便；离幻即觉，亦无渐次」——不必造作对治，识破即离，离处即觉。「究竟涅槃」即**复本心源**：涅槃不是新证得的一个境界，正是那个「无始菩提涅槃元清净体」——本自清净，今始亲归。

*术语*：
- **四颠倒** = 于**无常**执常 / 于**苦**执乐 / 于**无我**执我 / 于**不净**执净
- **梦想** = 长夜大梦——迷时之有，如梦中境；觉后了不可得
- **复本心源** = 返妄归真之极——归无所归，还其本来

*参考*：
- 《圆觉经》：「知幻即离，不作方便；离幻即觉，亦无渐次。」
- 《楞严经》：「无始菩提涅槃元清净体。」

### 诸佛同依般若成佛

#### 三世诸佛，依般若波罗蜜多故，得阿耨多罗三藐三菩提

*白话*：过去、现在、未来的一切佛，都依般若波罗蜜多，证得无上正等正觉。

*解释*：三世诸佛，同证此心——成佛不是新造出一尊佛，而是众生本具的觉性彻底显发圆满。「是心是佛，是心作佛」：是心**本来是**佛（性德本具），依般若熏修而**作**佛（修德显本）——性德不因修而生，修德不离性而立。「得」而无所得：所得的菩提即是本有之觉，如拭镜得明，明不从外来——与上文「无智亦无得」呼应，两不相违。

*术语*：
- **三世** = 过去 / 现在 / 未来
- **阿耨多罗三藐三菩提** = anuttarā samyak-saṃbodhi = **无上正等正觉**——「无上」（更无有上）+「正等」（遍知平等）+「正觉」（真实觉悟）
- **性德 / 修德**：本具之德 / 熏修显发之功——修德有功，性德方显

*参考*：
- 《大乘起信论》：「所言法者，谓众生心；是心则摄一切世间法、出世间法。」
- 《观无量寿佛经》：「是心作佛，是心是佛。」

## 第六分 · 总赞与咒：显密双说

### 四叹般若

#### 故知般若波罗蜜多，是大神咒，是大明咒，是无上咒，是无等等咒

*白话*：所以应当知道：般若波罗蜜多是大神咒，是大明咒，是无上咒，是无等等咒。

*解释*：以「咒」赞叹般若：咒即总持，以少字总摄无量义——正如本经以 260 字总持六百卷之要。般若的「神力」不从外来：本觉智光一透，无明暗宅自明，即是大明；客尘不敌性光，狂心遇照即歇，即是大神。

*术语*：
- **咒** = 总持（陀罗尼，dhāraṇī）——以少字**总摄无量义**而不失
- **四叹**：**大神咒**（神力大——性光一照，客尘自散）/ **大明咒**（光明大——本觉透出，长夜自晓）/ **无上咒**（更无一法在其上）/ **无等等咒**（无有能与之等者；一说：与「无等」之佛果相等）

#### 能除一切苦，真实不虚

*白话*：（般若）能除灭一切苦，真实而不虚妄。

*解释*：呼应总纲「度一切苦厄」——开头标宗，这里结成，全经首尾圆合。度苦的路在如来藏教说得最亲切：苦由认妄，识真则狂歇，歇即菩提——般若不是玄谈，度苦是回光返照当下可以验证的真实受用。

*术语*：
- **真实不虚** = 佛语诚谛——劝信之辞

### 说咒

#### 故说般若波罗蜜多咒，即说咒曰：揭谛揭谛，波罗揭谛，波罗僧揭谛，菩提萨婆诃

*白话*：所以宣说般若波罗蜜多咒，咒是这样说的：揭谛揭谛，波罗揭谛，波罗僧揭谛，菩提萨婆诃。

*解释*：前文以义理**显说**般若（相妄性真、返妄归真），末后以咒语**密说**般若——显说令人依解起行，密说令人离解直行；一显一密，同归「度到彼岸」。咒依例音译不翻，属玄奘「五种不翻」中的**秘密不翻**：重在音声总持、一心受持，不重字面训解。

*术语*：
- 梵音：**gate gate pāragate pārasaṃgate bodhi svāhā**
- 通行释义：**揭谛**（去 / 度）/ **波罗揭谛**（到彼岸去）/ **波罗僧揭谛**（大家一同到彼岸去）/ **菩提**（觉悟）/ **萨婆诃**（速疾成就、圆满吉祥）——大意是：去吧！去吧！到彼岸去吧！大家一同到彼岸去吧！觉悟，速疾成就！

## 附三：「空」的正解与误解对照（如来藏）

| | 误解的「空」 | 如来藏的「空」 |
| --- | --- | --- |
| 定义 | 什么都没有、不存在 | **妄相无体、客尘本空**——空的是染妄之相，不是空掉真心 |
| 与现象的关系 | 否定现象（断灭见） | **全相即性**——相虽妄而性真，见色闻声全体是藏性之用 |
| 与真实的关系 | 空掉一切，无有真实 | **不空如来藏**——本具恒沙性德，真实不空 |
| 与修行的关系 | 既然皆空，无可修证 | **修德显本**——染是客尘故可除，觉是本具故可显 |
| 与「心」的关系 | 把攀缘妄心当作真心 | **真心离相**——识心缘影非真心；真心亦不可执为一物 |
| 空本身 | 执「空」为一个实有的东西 | **能所双泯**——始觉合本，无智亦无得 |

**一句话总结**：《心经》的「空」，如来藏读来就是「**相妄性真**」——空掉的是客尘妄染与所执之相，空不掉的是本自清净、不生不灭的真心。「无」字扫尽妄相，正为显出「无始菩提涅槃元清净体」：全经 260 字，是一封唤醒梦中人的家书——狂心若歇，歇即菩提。
