# 佛

## 词条概要

| 项 | 内容 |
| --- | --- |
| **梵语** | Buddha（बुद्ध） |
| **巴利语** | Buddha |
| **音译** | 佛陀（全称），简称"佛"。古译又作浮陀、浮图、浮屠、勃陀、没驮等 |
| **意译** | 觉者、觉悟者、知者 |
| **词源** | 动词词根 √budh（觉醒、知晓）的过去分词，字面义即"已觉醒者" |

---

## 一、基本定义（入门理解）

**佛，是对一类人的称号** —— 他们透彻地觉悟了生命与世界的真相，并能引导他人同样觉悟。

理解"佛"这个字,最简单的入口是三层"觉":

1. 1. **自觉**:自己从无明（不明真相的根本错觉）中醒来。
2. 2. **觉他**:能让别人也醒来。
3. 3. **觉行圆满**:自觉与觉他的能力、功德都达到圆满,再无遗漏与不足。

凡夫连自觉都没有;声闻、缘觉（罗汉、辟支佛）只有自觉,没有觉他的愿与行;菩萨自觉觉他都做,但还没圆满;只有这三者都圆满者,才被尊称为"佛"。

> **一句话**:佛 = 彻底醒来 + 能唤醒他人 + 这件事做到极致 的觉悟者。

## 二、进阶理解（中级）

### 1. "觉"的两层含义

古代注疏家（隋·慧远《大乘义章》）把"觉"拆成两个层面:

* **觉察 / 警觉**:对治"烦恼障"。烦恼像贼,会偷走人的安宁与善行;佛对这些贼了了分明,不被劫掠。
* **觉悟 / 醒觉**:对治"所知障"。无明像沉睡,使人对事物的真实结构看不清;佛如人睡醒、莲花开放,对一切法的本质豁然明了。

前者解决"心病",后者解决"认知盲点"。两者都圆满,才是佛。

### 2. 与其他修行果位的对照

| 身份 | 自觉 | 觉他 | 圆满 |
| --- | --- | --- | --- |
| 凡夫 | ✗ | ✗ | ✗ |
| 声闻、缘觉 | ✓ | ✗ | ✗ |
| 菩萨 | ✓ | ✓ | ✗ |
| **佛** | **✓** | **✓** | **✓** |

### 3. 佛的特质与能力

经典中描述佛具有多项不共于其他人的能力体系:

* **三十二相、八十种好**:身体层面的庄严特征。
* **十力**:对一切法的十种了知力。
* **四无所畏**:说法时四种无可挑战的自信。
* **十八不共法**:十八项二乘所无的能力,如身无失、口无失、念无失等。
* **大定、大智、大悲**:分别对应**断德**（断尽烦恼）、**智德**（圆满智慧）、**恩德**（救度有情）"三德"。

### 4. 佛的别名为何那么多?

经典中称呼佛的方式极多。这并非不同实体,而是从不同侧面突显佛的功德。常见有:

* **功能性称号**:如来、应供、正遍知、明行足、善逝、世间解、无上士、调御丈夫、天人师、佛、世尊（合称"如来十号")。
* **比喻性称号**:法王（教法之王)、大医王（应病与药)、世雄（断烦恼之雄)、世眼（世间引路人)、佛日（如太阳)、人中师子、两足尊（两足众生中最尊;亦解作"福慧具足者")等。

## 三、深入理解(高级)

### 1. 时间维度上的"佛"

佛不是单一的人物,而是一个跨越时间的现象:

* **过去佛**:已在过去世出现的佛,如"过去七佛"、燃灯佛等。
* **现在佛**:本师释迦牟尼;大乘则更说他方世界同时存在的诸佛。
* **未来佛**:将于此娑婆世界出现的弥勒佛。
* **三劫三千佛**:庄严劫、贤劫、星宿劫各有千佛,共三千佛(详见《三劫三千佛名经》)。

### 2. "一时几佛"—— 部派的著名争论

| 学派 | 主张 |
| --- | --- |
| 上座部·有部 | **多界一佛**一个三千大千世界,同时只能有一位佛 |
| 大众部 | **一界一佛,多界多佛**每个世界各可同时有一佛 |
| 大乘 | **十方诸佛并存**东方阿閦佛、西方阿弥陀佛等同时在他方现在,数如恒沙 |

这一分歧背后,是对"佛"究竟是历史中独一现象,还是法界中普遍可能事件的不同看法。

### 3. "佛究竟是什么": 四大思想系统的不同诠释

不同传承对"佛是什么"有不同的强调点。这不是矛盾,而是从不同侧面切入同一果位。

#### (a) 根本佛教 / 部派佛教

佛是历史中的觉悟者,首先指释迦牟尼。重点在于:

* 佛是**无师而自觉**、"自然觉、一切种觉"的圣者。
* 佛与阿罗汉同样断尽烦恼、获得解脱;但佛是**先觉、遍觉、别觉** —— 开路者,而阿罗汉是追随者。
* 《大毘婆沙论》详列佛与二乘的差别,如著名的"三兽渡河"喻:二乘渡缘起之河如兔、马浮渡水面,佛如香象足蹈河底。
* 此期更重视"佛的功能"(觉与导师),而非"佛的本体"。

#### (b) 中观派(龙树系)

以"性空"为根本,对"佛"的诠释:

* 佛是彻见诸法**缘起性空**者。
* 佛之所以为佛,不是因为得到了什么实体性的"佛体",而是因为彻底放下了一切自性见。
* 严格来说,"佛"亦不可执为实有 —— 执"有佛可成"也是戏论。
* 在二谛中:世俗谛上有佛可见可礼;胜义谛上佛与众生同一空性,无佛可得,无众生可度。

#### (c) 唯识 / 法相宗(无著、世亲系)

从"识转智"的角度定义佛:

* 佛是**转八识成四智**者:转第八识为大圆镜智、转第七识为平等性智、转第六识为妙观察智、转前五识为成所作智。
* 佛是**二障俱断**者 —— 同时断尽**烦恼障**与**所知障**(二乘只断烦恼障)。
* 《大毘婆沙论》另说佛具"因智、时智、相智、说智"四种圆满认知能力。
* 佛身分为**自性身、受用身、变化身**(三身说在此系统中最为细密)。

#### (d) 如来藏 / 佛性系

如来藏系经典(《如来藏经》《胜鬘经》《大般涅槃经》《楞伽经》等)作出最具突破性的诠释:

* **一切众生本具如来藏(佛性)** —— 成佛不是"获得"什么新东西,而是"显发"本来就有的。
* 佛是如来藏完全显现、客尘烦恼彻底脱落的状态。
* 此系是后来禅宗"即心是佛"、"见性成佛"思想的直接源头。
* **须注意**:这里所说的"佛性"不是外道所执的"神我"或恒常自体,而是**空性与觉性的不二**。这是该系统最容易被误读的地方。

### 4. 佛"身"的层次:大乘三身说

大乘以"三身"统摄"佛是什么":

| 身 | 梵语 | 性质 | 类比 |
| --- | --- | --- | --- |
| **法身** | Dharmakāya | 佛所证的真理本身,遍一切处,无形无相 | 真理本身 |
| **报身** | Saṃbhogakāya | 无量劫修行所感得的庄严身,于净土为大菩萨说法 | 真理的圆满显现 |
| **化身** | Nirmāṇakāya | 为度化众生应机示现的身相,释迦牟尼即化身佛之代表 | 真理的应机表达 |

## 四、常见误解辨正

| 误解 | 正解 |
| --- | --- |
| 佛是神,能赐福降祸 | 佛是觉者、导师,不是创世主或赏罚之神 |
| 佛只有释迦牟尼一位 | 此为早期观点;大乘明言三世十方诸佛 |
| 念佛号就是迷信 | 念佛是修行方法之一,目的是收摄心念、与佛德相应 |
| 成佛要等无量劫,与我无关 | 各系皆有当下入手处;如来藏系更直指"本来是佛" |
| 佛是某种神秘体验 | 佛果是智、定、悲三德具足,不仅是觉受,更是觉、断、行的圆满 |
| 佛性 = 灵魂 / 自我 | 佛性不是恒常的"我",而是空性与觉性的不二 |
