## 一、简体（公众号 / B 站 / 视频号）

1. 《八识规矩颂》第二讲 · 第六识颂｜意识：三业造业主、初地就转依的「全能识」
2. 为什么造业主是第六识，不是第七、第八？——玄奘大师用 12 句颂讲透意识
3. 妙观察智能亲证真如，成所作智只能后得——第六识 vs 前五识 转依到底差在哪？

### 简短摘要（视频号 / 朋友圈 100 字）

第六识 = 意识——三界九地全现行、51 个心所都相应、三种分别全有，是最全能的一识。

三业里的「动身、发语、意」，全靠第六识总指挥，引业 + 满业招感三界果报。

转依起步最早——初地欢喜地就发起妙观察智，七地末纯无漏，佛果观察圆明照大千。

### 完整描述（公众号 / B 站正文）

《八识规矩颂》系列**第二讲**——玄奘大师用 3 颂 12 句，把**第六识（意识）**的凡夫运作 + 圣者转依 讲透。

**立场**：玄奘唯识 / 法相宗（跟第一讲一致）。校验依据——《成唯识论》卷 5-7、卷 9-10 + 《瑜伽师地论》卷 3 / 51-52。

#### 本期核心论断

1. **第六识 = 最全能**——三性三量三境全通、三界九地全现行、51 个心所都相应、三种分别（自性 + 计度 + 随念）全有
2. **第六识 = 三业造业主**——「动身发语独为最」，引业 + 满业招感三界果报
3. **第六识转依起步最早**——初地欢喜地发起妙观察智；**七地末**俱生我执**现行永伏**（八地起纯无漏）；**佛果**俱生我执 / 法执 **种子皆断**
4. **妙观察智 vs 成所作智**——妙观察智可起根本无分别智，直接亲证真如；成所作智唯变相观空、只能后得

#### 第六识颂 三颂 全文

**第一颂** · 凡夫位基本特征
```
三性三量通三境    三界轮时易可知

```

**第二颂** · 凡夫位造业主
```

动身发语独为最    引满能招业力牵
```

**第三颂** · 圣者位转依
```
发起初心欢喜地    俱生犹自现缠眠
远行地后纯无漏    观察圆明照大千
```

#### 几个 反常识 的校验点

- **「三性三量通三境」**：第六识 三性、三量、三境**全通**——前五识唯性境唯现量，能力差别很大
- **「三界轮时易可知」**：三界九地**全都**现行，唯除**五位无心**（无想定 / 无想天 / 灭尽定 / 极睡眠 / 极闷绝）暂断
- **「相应心所五十一」**：51 个心所**全部**相应——前五识只 34（小随 10 + 慢/疑/不正见 + 不定 4 都不相应，因为五识无计度分别）
- **「性界受三恒转易」**：性、界、受**三样**都恒时变易——**「三」修饰前三字，不是「三种受」**；第六识通 5 受，前五识 3 受，第七识唯舍受
- **「动身发语独为最」**：意业为主，导引身语——前五识只被动感知；第七识内缘不外造业；第八识无记不造业
- **「引满能招业力牵」**：**引业** = 总报业（生哪一趣）；**满业** = 别报业（那一趣内长寿短寿贫富贵贱）
- **「发起初心欢喜地」**：菩萨登**初地见道**那一刹那，妙观察智一分现前，顿断三界分别惑
- **「俱生犹自现缠眠」**：严格分两层——**现行**七地末永伏；**种子**要到**金刚喻定 / 佛果**才彻底断尽（一般说「俱生我执断尽」实际指现行永伏）
- **「远行地后纯无漏」**：七地末 → 八地起 无功用道，第六识起心动念全是无漏
- **「观察圆明照大千」**：佛果妙观察智**说法断疑**度众生——大圆镜智、平等性智都不做这个

#### 见道所缘：真如（不是「加真如境」）

见道是**一刹那**亲证 **二空真如**（无有相分），不缘性境 / 带质境 / 独影境三境。修道位才通「入观缘真如 + 出观缘有为诸法」。这一点跟前讲说的「三境」是完全不同的层面。

#### 幾個 反常識 的校驗點

- **「三性三量通三境」**：第六識 三性、三量、三境**全通**——前五識唯性境唯現量，能力差別很大
