## 一、简体（公众号 / B 站 / 视频号）

### 标题候选

1. 《八识规矩颂》第二讲 · 第六识颂｜意识：三业造业主、初地就转依的「全能识」
2. 为什么造业主是第六识，不是第七、第八？——玄奘大师用 12 句颂讲透意识
3. 妙观察智能亲证真如，成所作智只能后得——第六识 vs 前五识 转依到底差在哪？

### 简短摘要（视频号 / 朋友圈 100 字）

第六识 = 意识——三界九地全现行、51 个心所都相应、三种分别全有，是最全能的一识。

三业里的「动身、发语、意」，全靠第六识总指挥，引业 + 满业招感三界果报。

转依起步最早——初地欢喜地就发起妙观察智，七地末纯无漏，佛果观察圆明照大千。

### 完整描述（公众号 / B 站正文）

《八识规矩颂》系列**第二讲**——玄奘大师用 3 颂 12 句，把**第六识（意识）**的凡夫运作 + 圣者转依 讲透。

**立场**：玄奘唯识 / 法相宗，校验依据《成唯识论》卷 5-10。

#### 三颂 全文

```
三性三量通三境    三界轮时易可知
相应心所五十一    善恶临时别配之

性界受三恒转易    根随信等总相连
动身发语独为最    引满能招业力牵

发起初心欢喜地    俱生犹自现缠眠
远行地后纯无漏    观察圆明照大千
```

#### 四个核心论断

1. **最全能**——三性三量三境全通、三界九地全现行、51 个心所都相应、三种分别（自性 + 计度 + 随念）全有
2. **三业造业主**——「动身发语独为最」，引业 + 满业招感三界果报
3. **转依起步最早**——初地欢喜地一分现前；**七地末**俱生我执**现行永伏**（八地起纯无漏）；**佛果**种子才彻底断尽
4. **妙观察智** 可起 根本无分别智 直接亲证真如；**成所作智**（五识转成）唯变相观空

#### 三处 反常识 校验点

- **「性界受三」的「三」修饰前三字**（性、界、受 三样恒转易），**不是「三种受」**——第六识通 5 受（苦乐忧喜舍），前五识 3 受（无忧喜），第七识唯舍受
- **「俱生犹自现缠眠」严格分两层**——**现行** 七地末永伏；**种子** 要到金刚喻定 / 佛果 才彻底断尽（一般说「俱生我执断尽」实际指现行永伏）
- **见道所缘 = 真如**——见道是一刹那亲证二空真如，不缘性境 / 带质境 / 独影境三境；修道位才通「入观缘真如 + 出观缘有为诸法」

1. **最全能**——三性三量三境全通、三界九地全現行、51 個心所都相應、三種分別（自性 + 計度 + 隨念）全有
