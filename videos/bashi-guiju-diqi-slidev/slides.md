# 第七识 ↔ 百法

<div class="text-lg space-y-2 mt-3">

- 「末那」= 梵语 manas，义为「意」——为区别第六**意识**，音译为「末那」
- 体性：**恒审思量**——**从来不断**（对比前六识：五位无心时暂断）
- 所依：**第八阿赖耶识**
- 所缘：**第八识的见分**——执之为「我」（实际第八本身**无我**）
- 起处：**三界九地恒起**（除入无余涅槃）

</div>

<div class="mt-4 p-3 bg-amber-50 rounded text-base">
<strong>三个「唯」</strong>——<strong>唯带质境</strong> / <strong>唯非量</strong> / <strong>唯有覆无记</strong><br>
相应 <strong>18 个心所</strong>（比第六识少 33 个）；<strong>四烦恼常俱</strong>（我痴 / 我见 / 我慢 / 我爱）

# 第一颂 · 第二句详解：随缘执我量为非

<div class="mt-2 p-3 bg-amber-50 rounded text-lg">
<strong>白话</strong>：末那 <strong>随所缘境</strong>（第八见分）执之为「<strong>我</strong>」；这个认识是错的，所以三量 <strong>唯非量</strong>。
</div>

<div class="space-y-3 mt-4 text-base">

- 「执我」= 把第八见分（其实是识的**功能**，不是「我」）执为常一的「我」

<li>第六识：<strong>三量全通</strong>（现量 / 比量 / 非量 都能起）</li>
<li>第七识：<strong>唯非量</strong>（结构性错认第八见分为「我」）</li>
</ul>
