# 第八识 ↔ 百法 · 三个名字

<div class="text-base space-y-2 mt-3">

- 「阿赖耶」= 梵语 ālaya，义为「**藏**」—— 凡夫 至 七地末 的名称
- 「异熟」= 梵语 vipāka，酬引业招异熟果 —— **八地** 至 金刚道 的名称
- 「无垢识」= amala-vijñāna —— **佛果** 的名称（同时叫「大圆镜智」）
- 体性：**恒但非审**（相续不断，无审察）
- 三性 **唯无覆无记** / 三量 **唯现量** / 三境 **唯性境** / 受 **唯舍受**
- 相应心所：**只 5 个遍行**（触、作意、受、想、思）——八识里 相应最少

</div>

<div class="mt-4 p-3 bg-amber-50 rounded text-base">
<strong>三义</strong>（能藏 / 所藏 / 执藏）<br>
<strong>四大功能</strong>（受熏 / 持种 / 根身 / 器）<br>
<strong>去后来先</strong>——生死轮回主体
</div>

# 第一颂 · 第一句详解：性唯无覆五遍行

<div class="mt-2 p-3 bg-amber-50 rounded text-lg">
<strong>白话</strong>：第八识 三性 <strong>唯无覆无记</strong>；相应心所 <strong>只 5 个遍行</strong>（触、作意、受、想、思）——八识里 相应最少。
</div>

<div class="space-y-3 mt-4 text-base">

- 「无覆」= 不覆蔽真理（对比末那「有覆」）；「无记」= 非善非恶
- 「5 遍行」= 触、作意、受、想、思，一切心识必伴
- **为什么只 5 遍行？** —— 第八 体性微细、恒相续、无审察，其他 46 心所 特征太粗，不相应

</div>

<div class="mt-4 p-3 bg-amber-50 rounded text-base">
<strong>相应心所对比</strong>——
<ul class="mt-1">
<li>前五识：34 个</li>
<li>第六识：51 个（全通）</li>
<li>第七识：18 个</li>
<li><strong>第八识：只 5 个</strong>（最少）</li>
</ul>
</div>

# 第一颂 · 第二句详解：界地随他业力生

<div class="mt-2 p-3 bg-amber-50 rounded text-lg">
<strong>白话</strong>：第八识 在三界九地 <strong>随业力</strong> 招感——「他」= 业力；<strong>不能自主</strong>选择在哪界哪地。
</div>

<div class="space-y-3 mt-4 text-base">

- 「界地」= **三界九地**（欲界 + 色界四禅 + 无色界四禅）
- 「随他」= 随「他」（业力）而生，不能自主
- 「业力生」= 前生 引业 决定 今生 生哪一界

</div>

<div class="mt-4 p-3 bg-amber-50 rounded text-base">
举例——
<ul class="mt-1">
<li>造上品十善 → 引 生天</li>
<li>造十恶 → 引 堕地狱</li>
<li>造中品十善 → 引 生人道</li>
</ul>
</div>

<div class="mt-3 p-3 bg-stone-50 rounded text-sm">
<strong>划重点</strong>：第八识 是 <strong>异熟识</strong>——「异熟」= 酬引业招异熟果，专门 承受 业力果报
</div>

# 第二颂 · 第二句详解：渊深七浪境为风

<div class="mt-2 p-3 bg-amber-50 rounded text-lg">
<strong>白话</strong>：第八识 <strong>深如渊</strong>；前七识 如 <strong>七浪</strong>；所缘境 如 <strong>风</strong>（吹起浪）。
</div>

<div class="space-y-3 mt-4 text-base">

- 「渊深」= 阿赖耶 深不可测（如海）
- 「七浪」= 前七识（前五 + 六 + 七）如七种波浪
- 「境为风」= 所缘境 如风，吹动波浪起

</div>

<div class="mt-4 p-3 bg-amber-50 rounded text-base">
意思：<strong>前七识依阿赖耶而起</strong>（如浪起于海）；境界为缘（风），才有波浪。
</div>

<div class="mt-3 p-3 bg-stone-50 rounded text-sm">
<strong>划重点</strong>：这一句概括 唯识 <strong>根本原理</strong>——万法（前七识）依第八识而起，这就是「万法唯识」的深意
</div>
