## 一、第六识 速览（1 页）

### P4 · 第六识 ↔ 百法 · 基本特征
- 第六识 = 百法 心法 8 识 里 的 第六个（意识）
- 体性：**了别 一切法**——不限于 5 尘，法尘也缘
- 所缘：法尘（含 一切法）
- 所依：意根（第七末那）
- 起处：**三界九地 全** 现行（对比 五识 只有欲界+初禅部分二地）
- 两种起法：
  - **五俱意识**——跟五识 同时起（比如 眼识见色 时 第六识 同缘）
  - **独头意识**——独自起（比如 定中、梦中、独散思考）
- 划重点框：具足 **三种分别**（自性 + 计度 + 随念）—— 三业造业主

  - 第四句：**善恶配伍方式**（临时决定）

### P7 · 第一颂 · 第一句详解：三性三量通三境
- **白话框**：第六识 三性、三量、三境 全通——比五识 多通两维（量 + 境）
- 三性 = 善 / 恶 / 无记 全能起
- 三量 = 现量 / 比量 / 非量 全能起（现量：五俱意识；比量：正确推理；非量：错误推理）
- 三境 = 性境 / 带质境 / 独影境 全能缘
  - 性境（跟五识同缘色声香味触）
  - 带质境（缘他人心 或 缘自己心相状态）
  - 独影境（缘梦、想象、龟毛兔角）
- 对比表：五识 vs 六识（境/量/性 三维度）

### P8 · 第一颂 · 第二句详解：三界轮时易可知
- **白话框**：三界九地——欲界、色界四禅、无色界四禅——**全都** 现行 第六识
- 「轮时」= 三界 六道 轮回时；「易可知」= 最易观察
- 对比 五识：欲界全有；色界初禅 只三识；二禅以上 全不起
- 第六识 独一无二——**全三界全九地**（除 无想天、灭尽定 短暂 中断）
- 划重点框：所以「三界轮回 主要靠 第六识 造业」

### P9 · 第一颂 · 第三句详解：相应心所五十一
- **白话框**：**51 心所全部** 都可以跟 第六识 相应——是 8 识里 相应最多的
- 表格 展示 51 分类：
  - 遍行 5 / 别境 5 / 善 11 / 根本烦恼 6（贪嗔痴慢疑恶见）/ 大随 8 / 中随 2 / 小随 10 / 不定 4
- 对比 五识：只 34 个（小随 10、慢/疑/恶见、不定 4 都不相应）
- 第六识 具足 三种分别，所以 计度分别 类 烦恼（小随 10、慢疑恶见、不定 4）全能起

### P10 · 第一颂 · 第四句详解：善恶临时别配之
- **白话框**：具体 起善 / 起恶 / 起无记，**临时** 根据 缘境 决定——不是 恒定 一种性
- 「临时」= 当下 那一刹那 决定
- 「别配」= 按 那一刹那 遇到的境、跟 相应心所 搭配 决定 三性
- 举例：
  - 见 佛像 起 敬心——善（跟 信、无贪、无嗔 等 相应）
  - 见 仇人 起 嗔心——恶（跟 嗔 相应）
  - 见 风景 无所思——无记（只跟 遍行 相应）
- 对比 第七识：**恒审思量**——恒 起 我执，从来不 是 善——性一定是 有覆无记

### P11 · 第二颂 全文
- 完整颂文四句居中大字
- 简述：第二颂讲 4 个维度——
  - 第一句：**性界受 三 恒转易**（三性 三界 三受 都 恒时变易）
  - 第二句：**根随信等 总相连**（根本烦恼 + 随烦恼 + 善心所 全都能相连）
  - 第三句：**动身发语 独为最**（造业能力 三业 全靠 第六识）
  - 第四句：**引满能招 业力牵**（引业 + 满业 全由 第六识 造）

### P12 · 第二颂 · 第一句详解：性界受三恒转易
- **白话框**：三性、三界、三受——**三个维度** 都 恒时 变易，第六识 从不 定 在一个 状态
- 三性——善 / 恶 / 无记 交替
- 三界——欲 / 色 / 无色 生 到 哪界 现行 哪界
- 三受——苦 / 乐 / 忧 / 喜 / 舍 交替
- 「恒转易」= 永远 在变
- 对比 第七识：三受 **唯舍受**，从不 变；三性 **唯有覆无记**，从不 变；三界 恒 起（无 变）
- 划重点框：所以 第六识 = 最灵活；第七识 = 最恒定

### P13 · 第二颂 · 第二句详解：根随信等总相连
- **白话框**：根本烦恼、随烦恼、善心所（信 精进 等）—— 都跟 第六识 相应
- 「根」= 6 根本烦恼（贪嗔痴慢疑不正见）
- 「随」= 20 随烦恼（大 8 + 中 2 + 小 10）
- 「信等」= 11 善心所（信 精进 惭 愧 无贪 无嗔 无痴 轻安 不放逸 行舍 不害）
- 加上 遍行 5、别境 5、不定 4 = 51 心所全部
- 对比 五识 只 34：小随 10 + 慢/疑/不正见 + 不定 4 都不相应（因为 五识 无计度分别）
- 第六识 具三种分别 → 计度分别 类 心所 全能起

### P14 · 第二颂 · 第三句详解：动身发语独为最
- **白话框**：三业里的**身业**（动身）和**语业**（发语），造业能力 第六识 **最强、独一**
- 「动身」= 引发身体行动
- 「发语」= 引发言语造作
- 「独为最」= 8 识里 独 第六识 有 这个 能力，且 最强
- 为什么 只第六识 能：
  - 五识 只 了别当下 尘境，不能 主动 引发
  - 第七识 只 内缘 第八识 见分，不外造业
  - 第八识 是 无记 藏识，不 造业
- 意业 = 第六识 起心动念 本身就是
- 划重点框：所以《八识规矩颂》说 造业主 = 第六识

### P15 · 第二颂 · 第四句详解：引满能招业力牵
- **白话框**：第六识 造 引业 + 满业，两种 业力 都能 招感 三界果报
- 拆解 两个 术语：
  - **引业**——引导 生 哪一趣 的 主业。比如：造 上品 十善 → 引 生天；造 十恶 → 引 堕地狱。**一期 生死 主报**（总报）
  - **满业**——决定 那一趣 具体 别报的业。比如：同 生人道，长寿 / 短寿 / 富贵 / 贫穷 是 满业 决定的（别报）
- 「能招」= 招感 相应果报
- 「业力牵」= 业力 牵引 众生 六道 轮回
- 划重点框：所以《成唯识论》说「意业为主，导引身语」

### P16 · 凡夫位 小结
- 一段 综合话：**凡夫位 的 第六识**——
  - 3 性 3 量 3 境 全通，三界九地 全现行
  - 51 心所全应，临时 决定 起 善恶无记
  - 三业造业主（动身 发语 独为最），引满业 招感 三界果报
  - 具足 三种分别（自性 + 计度 + 随念）
- 对比 五识 只是 现量 感知；对比 七识 只是 恒审 我执；**只有 第六识 是「造业主」**

### P19 · 第三颂 · 第一句详解：发起初心欢喜地
- **白话框**：菩萨 登 **初地 欢喜地** 那一刹那——第六识 的转依 就 **发起** 了
- 拆解：
  - 「初心」= 初地 见道位 那一心，也叫 通达位
  - 「欢喜地」= 十地 第一地
  - 「发起」= 妙观察智 初现（先起 一分 无漏 无分别智）
- 见道时——顿断 一切 **分别起** 烦恼（三界 分别惑 88 使 一时 断尽）
- 但 **俱生起** 烦恼 还没 全断（下一句 讲）
- 划重点框：所以《八识规矩颂》说「发起 初心 欢喜地」

### P20 · 第三颂 · 第二句详解：俱生犹自现缠眠
- **白话框**：登初地后 一直到 七地，第六识 里 的 **俱生烦恼** 仍然 会现行 或 潜伏（种子）
- 拆解：
  - 「俱生」= 与生俱来 的 我执 法执（对比 见道 断 的 分别起）
  - 「缠」= 现行（现前 显现）
  - 「眠」= 种子潜伏（未现行 但 有种子）
- 二至六地 修道位：渐次 断除 俱生烦恼 现行
- 划重点框：所以 见道位 只 一时 断 分别惑；俱生惑 靠 修道 长时 渐断

### P21 · 第三颂 · 第三句详解：远行地后纯无漏
- **白话框**：菩萨 修到 **七地 远行地** 之后——第六识 才 **纯无漏**（不再 起 有漏心）
- 拆解：
  - 「远行地」= 十地 第七地
  - 「后」= 七地 圆满 进入 八地
  - 「纯无漏」= 第六识 里 有漏种子 已断，起心动念 全是 无漏
- 七地 是 关键转折——之前 有漏 无漏 交杂；八地起 纯无漏
- 八地 = 不动地——无功用行 任运 起 妙观察智
- 划重点框：五识 转依 要 等 佛果一刹那；第六识 七地就 纯无漏 —— 时机 早 得多

### P22 · 第三颂 · 第四句详解：观察圆明照大千
- **白话框**：佛果 位 妙观察智 **观察圆满明朗**，**遍照 三千大千世界**
- 拆解：
  - 「观察」= 妙观察智 的 特质——观察 诸法 自相 共相
  - 「圆明」= 圆满 明朗（佛果 圆满 无有 障碍）
  - 「大千」= 三千大千世界
- 妙观察智 果用——
  - 观察 诸法 自共相
  - 说法 度生（跟 众生 因缘）
  - 转法轮

### P23 · 妙观察智 vs 前五识的 成所作智 · 对比
- 两智 都是 转 有漏识 成 无漏智，但 能力 有区别
- 对比表：

| 维度 | 妙观察智（六识转）| 成所作智（五识转）|
|---|---|---|
| 转依起点 | 初地 见道 就 起（早）| 佛果 一刹那 才起（晚）|
| 纯无漏 | 七地 后 纯无漏 | 佛果 才 纯无漏 |
| 亲证真如 | **可以起 根本无分别智** | 只能起 后得智 |
| 观空方式 | 直接亲证 或 变相观空 都可 | 唯 变相观空 |
| 果用 | 观察 诸法 自共相 + 说法度生 | 现三类化身 度苦轮 |

- 划重点框：为什么 第六识 能 亲证 真如？——因为 具三种分别，能 舍相 直取 真如；五识 只 自性分别，必须 变相 才能 观

### P24 · 圣者位 小结
- 一段 综合话：**圣者位 的 第六识**——
  - 初地 欢喜地 就开始 转（比五识 早 得 多）
  - 见道 一刹那 顿断 分别惑，转 一分 无漏
  - 二至六地 修道位 渐断 俱生惑
  - **七地 后 纯无漏**
  - 佛果 妙观察智 圆满，观察圆明 照大千
- 对比 五识 = 佛果 一刹那 才转
- 依据 来自《成唯识论》卷 9-10 + 《瑜伽师地论》卷 51
