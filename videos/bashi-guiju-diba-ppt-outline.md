## 一、第八识 速览（1 页）

### P4 · 第八识 ↔ 百法 · 三个名字
- 「阿赖耶」= 梵语 ālaya，义为「**藏**」——凡夫 至 七地末 的名称
- 「异熟」= 梵语 vipāka，酬引业招异熟果——**八地** 至 金刚道 的名称
- 「无垢识」= amala-vijñāna——**佛果** 的名称（同时叫「大圆镜智」）
- 体性：**恒但非审**（相续不断，无审察）
- 三性：**唯无覆无记** / 三量：**唯现量** / 三境：**唯性境** / 受：**唯舍受**
- 相应心所：**只 5 个遍行**（触、作意、受、想、思）—— 8 识里 相应最少
- 划重点框：**三义**（能藏 / 所藏 / 执藏）；**四功能**（受熏 / 持种 / 根身 / 器）；**去后来先**

### P7 · 第一颂 · 第一句详解：性唯无覆五遍行
- **白话框**：第八识 三性 **唯无覆无记**；相应心所 **只 5 个遍行**（触、作意、受、想、思）——8 识里 相应最少
- 拆解：
  - 「无覆」= 不覆蔽真理（对比 末那「有覆」）；「无记」= 非善非恶
  - 「5 遍行」= 触、作意、受、想、思，一切心识必伴
  - 为什么 只 5 遍行？——第八 体性微细、恒相续、无审察，其他 46 心所 特征太粗，不相应
- 对比表：
  - 前五识 34、第六识 51、第七识 18、**第八识 5**
  - 第八 相应最少，最微细

### P8 · 第一颂 · 第二句详解：界地随他业力生
- **白话框**：第八识 在三界九地 **随业力** 招感——「他」= 指业力；不能自主选择在哪界哪地
- 拆解：
  - 「界地」= 三界九地
  - 「随他」= 随「他」（业力）而生，不能自主
  - 「业力生」= 前生 引业 决定 今生 生哪一界
- 举例：造上品十善 → 引 生天；造十恶 → 引 堕地狱
- 划重点：第八识 是 **异熟识**——「异熟」= 酬引业招异熟果

### P9 · 第一颂 · 第三句详解：二乘不了因迷执
- **白话框**：**二乘**（声闻、缘觉）**不了** 第八识存在——因为 迷执 于第六意识为「主体」
- 拆解：
  - 「二乘」= 声闻乘、缘觉乘
  - 「不了」= 不承认、不了解
  - 「因迷执」= 因为迷执于「六识为体」（二乘立场：只承认六识）
- 二乘立场：只讲 **六识**，不立 第七、第八
- 大乘唯识立场：**八识全立**（尤其 第八 阿赖耶）

### P10 · 第一颂 · 第四句详解：由此能兴论主诤
- **白话框**：由此（第八识存在 vs 二乘立场），**唯识论主** 兴起 **论辩**，建立 阿赖耶识教
- 拆解：
  - 「由此」= 由 二乘不了 第八 这个分歧
  - 「论主」= 唯识论主（弥勒、无著、世亲、护法等）
  - 「诤」= 论辩、争辩
- 主要论辩点：
  - 若无第八，**种子** 由谁执持？（业力如何相续？）
  - 若无第八，**生死主体** 是谁？
  - 若无第八，**根身器界** 由谁 相续 执持？
- 划重点：论主 用 十种理由 证明 第八识 必存在（详见《成唯识论》卷 3）

## 三、凡夫位 · 第二颂（5 页 + 小结 1 页）

### P11 · 第二颂 全文
- 完整颂文四句居中大字
- 简述：第二颂 讲 4 个维度——

  - 第二句：**七识如浪、境如风**（渊深七浪）

### P12 · 第二颂 · 第一句详解：浩浩三藏不可穷
- **白话框**：第八识 「浩浩」如大海，含 **三藏** 义——**能藏 / 所藏 / 执藏**，深不可穷
- 拆解 **三藏**：
  - **能藏**——能含藏 一切种子（种子的仓库）
  - **所藏**——被前七识 熏习（种子的容器）
  - **执藏**——被 第七识 执为「我」（跟末那关系）
- 「浩浩」= 广大无边
- 「不可穷」= 深广无尽
- 划重点：**「执藏」**是「阿赖耶」得名的关键——**八地起 舍执藏，就叫「舍藏识」**

### P13 · 第二颂 · 第二句详解：渊深七浪境为风
- **白话框**：第八识 **深如渊**；前七识如**七浪**；所缘境 如**风**（吹起浪）
- 拆解：
  - 「渊深」= 阿赖耶 深不可测（如海）
  - 「七浪」= 前七识（前五 + 六 + 七）如七种波浪
  - 「境为风」= 所缘境 如风，吹动波浪起
- 意思：**前七识依阿赖耶而起**（如浪起于海）；境界为缘 (风)，才有波浪
- 划重点：这一句 概括 唯识 **根本原理**——**万法（前七识）依第八而起**

### P14 · 第二颂 · 第三句详解：受熏持种根身器
- **白话框**：第八识 **四大功能**——**受熏 / 持种 / 执持根身 / 执持器世间**
- 拆解：

| 功能 | 说明 |
| --- | --- |
| **受熏** | 接受前七识（现行）的熏习，转成种子 |
| **持种** | 执持一切种子 不失（善恶业种、名言种） |
| **根身** | 执持有情的**有根身**（五根 + 净色根） |
| **器** | 执持**器世间**（山河大地、无情世界）|

- 划重点：**受熏 + 持种** 是种子论核心；**根身 + 器** 是唯识对世界的解释——所谓「三界唯心」

### P15 · 第二颂 · 第四句详解：去后来先作主公
- **白话框**：**死时最后离**（去后）、**生时最先来**（来先）——第八识是**生死轮回的主体**（「主公」= 主人翁）
- 拆解：
  - **去后**——死亡时，前七识先散灭；**第八识最后离身**（体温最后冷）
  - **来先**——受胎时，**第八识最先来结生**（然后其他七识渐次现起）
  - **作主公**——是生死轮回的**主人翁**
- 划重点：为什么 佛教说「不断灭、不常有」？——第八识 **相续不断** 但 **刹那生灭**（既非断灭 也非常一）

### P16 · 凡夫位 小结
- 一段综合话：**凡夫位 的 第八识**——
  - **恒但非审**——相续不断，无审察
  - **唯无覆无记 / 唯性境 / 唯现量 / 唯 5 遍行**——最微细
  - **浩浩三藏**（能藏 / 所藏 / 执藏）
  - **四大功能**（受熏 / 持种 / 根身 / 器）
  - **去后来先**——生死轮回的主体

### P19 · 第三颂 · 第一句详解：不动地前才舍藏
- **白话框**：菩萨修到 **不动地**（八地）之前——七地末 那一刹那，第八识 **舍「藏识」名**
- 拆解：
  - 「不动地」= 十地 **第八地**
  - 「前才舍藏」= 八地之前那一刹那（**七地末进入八地时**）舍「藏识」名
  - 「舍藏」= 舍「阿赖耶」名（三藏义中「执藏」义舍）
- 为什么八地舍藏？——第七识**俱生我执现行永伏**（跟 V8 讲的一致），不再执第八为「我」，「执藏」义舍
- 舍藏后叫什么？——**异熟识**（仍有异熟义，酬引业招果报）
- 划重点：这就是《八识规矩颂》第三讲第七识颂 说的「无功用行我恒摧」的**另一面**

### P20 · 第三颂 · 第二句详解：金刚道后异熟空
- **白话框**：菩萨修到 **金刚喻定**（十地末 等觉最后一刹那）**之后**——「异熟识」名 也 **空**掉
- 拆解：
  - 「金刚道」= 金刚喻定 = 十地末 等觉位 最后一刹那 无间道定
  - 「后」= 金刚喻定 之后 = **佛果一刹那**
  - 「异熟空」= 「异熟识」这个名 也 舍
- 为什么金刚道后 舍异熟？——**所有有漏种子**（含引业种子）**全断尽**，不再有「异熟果」，「异熟」义 舍
- 舍异熟后叫什么？——**无垢识**（一切有漏皆断，唯余无漏）
- 划重点：**七地末 舍藏** + **佛果 舍异熟** —— **三个名字对应三个阶段**

### P21 · 第三颂 · 第三句详解：大圆无垢同时发
- **白话框**：**佛果一刹那**——第八识转成的 **大圆镜智**（智）+ **无垢识**（识）**同时**现起
- 拆解：
  - 「大圆」= 大圆镜智
  - 「无垢」= 无垢识 = 佛果位 第八识 的名字
  - 「同时发」= 同时现起（智 + 识 一齐 转成）
- 大圆镜智 vs 无垢识 关系——**同体异名**（智是能证、识是所依）
- 划重点：**大圆镜智** 跟 **成所作智**（前五识转）**同时起**——都是佛果一刹那

### P22 · 第三颂 · 第四句详解：普照十方尘刹中
- **白话框**：**大圆镜智** 遍照 **十方 无量佛土**——像大圆镜 映现一切
- 拆解：
  - 「普照」= 大圆镜智 遍照
  - 「十方尘刹」= 十方 无量佛土（微尘般多）
  - 「中」= 之中
- 大圆镜智 的果用：
  - **现自性身**（法身）+ **自受用报身**
  - **持无漏种**
  - 映现一切法（如大圆镜）
- 划重点：**四智分工**——
  - 大圆镜智：**自性身 + 自受用**（第八主）
  - 平等性智：**他受用**（第七主，度十地菩萨）
  - 妙观察智：**说法度生**（第六主）
  - 成所作智：**现三类化身**（前五主，度凡夫二乘菩萨）

### P23 · 大圆镜智 vs 其他三智 · 对比
- 四智完整对比表：

| 智 | 转自 | 转依起点 | 主要果用 | 度化对象 |
| --- | --- | --- | --- | --- |
| **成所作智** | 前五识 | 佛果一刹那 | 现三类化身 | 凡夫、二乘、菩萨 |
| **妙观察智** | 第六识 | 初地初心 | 观察诸法自共相 + 说法断疑 | 一切众生 |

- 划重点：转依时机 **两组**——

  - 五识、八识：**佛果一刹那** 才起（转依晚，同时）
- **大圆镜智 = 佛的「根本智」**——法身、自受用 都由它主司

### P24 · 圣者位 小结
