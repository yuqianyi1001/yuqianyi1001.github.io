# 佛经注解（逐句白话和解释）

为一部佛经／颂文／论典写逐句注解文章，发布为 Jekyll 博客文章（`_posts/`）。

成文范例（动笔前先读一篇找体感）：
- `_posts/2026-09-06-heart-sutra-line-by-line.md` ——《心经》白话和解释（般若版），四层体例的定稿范本
- `_posts/2026-08-27-bashi-guiju-song-line-by-line.md` ——《八识规矩颂》逐句解释，颂文类的先例

文章骨架见 `references/template.md`。

## 第一步：确认三件事

动笔前与用户确认（对话中已给出的不必再问）：

1. **底本**：哪部经、哪个译本（如玄奘译本）。
2. **立场**：用哪一家义理解读（般若中观／唯识／如来藏／净土……）。同一部经可以出多个「版本」（如般若版、唯识版、如来藏版），**一篇只守一家**。
3. **校准基准**：该立场的根本经论 2–3 部（如般若版用《大般若经》《大智度论》《中论》），写进文首信息块，解释义理时以此为准。

## 四层体例（每句经文）

每句经文一个 `####` 标题（标题就是经文原文），下列四层，各司其职、不可混淆：

- ***白话***：**纯直译**，紧贴经文字面，通常一句话。不夹任何解释语——「当体」「也就是说」这类词出现在白话里就是越界，把它挪去解释层。
- ***解释***：义理展开，用**连贯的文字**（不是列表）。写这句在说什么、与上下文如何承接（枢纽句、首尾呼应要点出来）、按所选立场怎样正读、常见误读如何简别。
- ***术语***：名词定义、梵文对照、列表、对比——**条目式**。已在前文定义过的术语写「定义见某句」回指，不重复展开。
- ***参考***：引用其他经论的**原文**，单独列在术语之后，注明出处；仅在有引文的句子出现。引文不混入术语。

为什么分四层：读者各取所需——只想对照经文的看白话，想懂义理的看解释，查名词的看术语，想核对经证的看参考。层与层一混，几种读者都不好用。这是用户逐轮返工定下的体例，不要自行合并。

## 义理与用词的硬性要求

以下每一条都来自用户的明确修正，写任何一部经都适用：

1. **立场纯正**：只用选定立场的讲法，不混入他家表述。例：写般若版时，把「空即是色」讲成「空性本体变现出色」就是滑向如来藏的「性体起用」——应改为「空不在色外、离色无空可得」。拿不准某讲法是否串味时，在解释层明确简别（「不是说……而是说……」）。
2. **不贬抑其他乘／宗派**：不写「拣别小乘析法空」「部派阿毗达磨执法体实有」这类批判语。要凸显本立场特色时，改为**正面引经**——如引《杂阿含》232 经「此性自尔」说明《阿含》本有当下空义，把其他经教作为呼应而不是对立面。
3. **「破」只用于「执」，不用于法**：可以说「破执」「破执实有」「破执断灭」；不可以说「破四谛」「破十二因缘」「遮遣诸法」——法本自空，无一法被消灭，般若只是如实照见。对法一律说「X 不可得」「X 亦无自性」。
4. **不作判教归属**：不把法门配属某乘——「十二因缘＝缘觉乘所观」「四谛＝声闻乘所修」「凡夫所执」「二乘为浅」都不要写。菩萨同样修习这些法门。这类内容直接删除即可，不必写替代说明。（经文自身义理中的「凡圣」对举，如「在圣不增、在凡不减」，不在此列。）

## 文章结构

完整骨架和一句成品示例见 `references/template.md`。要点：

- frontmatter：`layout: post`、`title`（形如「《X 经》白话和解释（Y 版）」）、`description`（一句话摘要，兼作公众号 digest）、`excerpt`（留空）、`tags`（两空格缩进 ` - `）。发布公众号时再补 `thumb_media_id`（封面素材）与 `wechat_link`（发布后回填）。
- `# 写在前面`：说明文章缘起（有无对应视频等）；若计划出多版本，注明本篇立场并预告其余版本。
- 信息块：经名／内容／校准基准／立场／说明，五个列表项。
- 正文按科判分「分」：`## 第N分 · 标题`，分下可设 `###` 小节，句为 `####`；各分之间用 `---` 分隔。
- 附录 2–3 个对照表：全经科判一览、义理次第对照、正解与误解对照等。
- 落款：`—— 整理：愚千一`。

## 自查清单（写完全文过一遍）

- [ ] 每句白话都是纯直译，无解释语混入
- [ ] 每句解释是连贯文字，不是列表
- [ ] 所有经论引文都在「参考」层，未混入术语
- [ ] 全文搜「破」：破的对象全部是「执」
- [ ] 全文搜「乘」「凡夫」「二乘」「声闻」「缘觉」：无判教归属、无贬抑语
- [ ] 对照校准基准检查各分义理，无他家串味
- [ ] 术语在首次出现处定义，之后回指
